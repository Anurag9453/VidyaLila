# Topic 4: Ek Hi k Se Sab Kuch: The k-Method Aur Proofs

Topic 1 se Topic 3 tak tumne proportion ke kai auzaar jama kiye: ad = bc, invertendo se componendo-dividendo tak ke paanch property, aur teen terms ka rishta b² = ac. Har property ke liye alag chaal yaad rakhni padti thi. Ab ek **ek hi chaabi** milegi jo in sabko kholti hai, aur nayi cheezein bhi: a/b = c/d ka matlab hai "dono ratio ki value ek hi hai". Us ek value ko ek **naam** de do, k, aur proof ek seedhi line ban jaata hai.

---

## Atul aur wahi rang, do baar

Atul ke Papa ki rang-roghan (paint) ki dukaan hai. Shanivaar ko ek aunty aayi aur boli, "Beta, bilkul wahi narangi rang chahiye jo pichhli baar mere drawing-room ke liye banaya tha. Is baar poori chhat ke liye, zyada chahiye." Papa ke register mein likha tha: **laal : peela = 7 : 3.** Pichhli baar chhoti tin thi, is baar badi.

Atul ne dekha ki aunty ke pehle order mein laal 21 L aur peela 9 L gaya tha, aur is baar laal 35 L chahiye. "Peela kitna?" Atul ne copy mein likha: **21 : 9 = 35 : ?** aur cross-multiply karne ki jagah usne ek alag soch aazmayi. "Papa, har baar rang tab wahi aata hai jab hum **7 tin laal aur 3 tin peela** milayein, bas **ek tin ka size** badalta hai. Pichhli baar ek tin 3 L ka tha: 7 × 3 = 21, 3 × 3 = 9. Is baar tin ka size 5 L: 7 × 5 = 35, to peela 3 × 5 = 15 L."

Papa ne muskura kar kaha, "Ye 'ek tin ka size' hi to ratio ka raaz hai." Atul ke school ke puzzle club mein usne ye baat sunai, aur ek dost ne sawaal phenka: "Agar a/b = c/d ho, to (a² + c²)/(b² + d²) = ac/(bd) kaise sach hota hai?" Atul ne kaha: "Dono ratio ke liye **ek hi tin ka size** maan lo, aur sab khud khul jaayega." Chalo dekhte hain kaise.

## Part A: Ek tin ka size, yaani k

**Kyun?** a/b = c/d ka matlab ye nahi ki a = c aur b = d. Matlab ye hai ki "a, b ke kitne guna hai" aur "c, d ke kitne guna hai" ka jawab **ek hi** hai. Us ek jawab ko k kaho:

a/b = c/d = k

Ab a/b = k se dono taraf b se guna karne par **a = bk**, aur c/d = k se **c = dk**. Dhyan do: **ek hi k, kyunki dono ratio barabar hain.** Agar dono ki value alag hoti to ye proportion hota hi nahi.

```
Order 1 : ek tin = 3 L
laal    : [3 ][3 ][3 ][3 ][3 ][3 ][3 ] = 21 L
peela   : [3 ][3 ][3 ]                 =  9 L
Order 2 : ek tin = 5 L
laal    : [5 ][5 ][5 ][5 ][5 ][5 ][5 ] = 35 L
peela   : [5 ][5 ][5 ]                 = 15 L
```

> **Figure 4.1** – Atul ke dono order. Dono mein tin ki ginti wahi hai: laal ke 7 aur peela ke 3. Sirf tin ka size badla (3 L se 5 L). Isliye 21 : 9 = 35 : 15, aur dono ratio ki value 7/3 hai.

**Ye ad = bc se kaise milta hai?** a = bk aur c = dk lekar: ad = (bk)d = bdk aur bc = b(dk) = bdk. Dono barabar: ad = bc, jo Topic 1 ka product rule tha. To k-method naya kuch nahi todta, wahi baat doosre roop mein kehta hai, par aage kaam bahut aasaan karta hai.

### Example 1: k nikalkar baaki term

Laal : peela = 7 : 3 hai aur ek order mein peela 24 L hai. Laal?
Peela = 3 × (tin ka size) = 24, to tin ka size = 24 ÷ 3 = 8 L. Laal = 7 × 8 = **56 L.**
**Jaanch:** 56 : 24 = 7 : 3 (dono ko 8 se divide karne par) ✅.

### Example 2: k poori sankhya hi ho zaroori nahi

8, 12, 14, 21 mein 8/12 = 14/21 hai (dono 2/3). Yahan **a = bk**: 8 = 12 × k, to k = 2/3. Aur **c = dk**: 14 = 21 × (2/3) = 14.
**Jaanch:** ad = 8 × 21 = 168 aur bc = 12 × 14 = 168 ✅. (k aksar fraction hota hai: tin ka size "2/3" bhi ho sakta hai.)

## Part B: k se identity ka proof

**Chaal (har proof mein yehi):**

| Qadam | Kya karna hai |
|---|---|
| 1 | Likho: a/b = c/d = k |
| 2 | **Dono** a aur c ko badlo: a = bk, c = dk |
| 3 | Left side aur right side mein substitute karo |
| 4 | Common **factor** bahar nikalo (b, d ya k jo bhi poore sum mein ho) aur cancel karo |
| 5 | Dono side ko ek hi expression tak lao |

### Example 3: (a² + c²)/(b² + d²) = ac/(bd)

Atul ke dost ka sawaal. a = bk, c = dk lekar:

Left side: (b²k² + d²k²)/(b² + d²) = k²(b² + d²)/(b² + d²) = **k²** (k² dono terms ka common factor tha).
Right side: (bk)(dk)/(bd) = bdk²/(bd) = **k².**

Dono k² hain, to **left side = right side.** Proof pakka hone ke baad bhi number se ek baar check karna acchi aadat hai: a = 8, b = 12, c = 14, d = 21 (8/12 = 14/21).
**Jaanch:** (64 + 196)/(144 + 441) = 260/585 = 4/9 aur ac/(bd) = 112/252 = 4/9 ✅. (Dhyan: b² + d² ≠ 0 hona chahiye, jo b, d non-zero hone par apne aap hota hai.)

### Example 4: (5a − 2b)/(5a + 2b) = (5c − 2d)/(5c + 2d)

a = bk, c = dk. Left side: (5bk − 2b)/(5bk + 2b) = b(5k − 2)/(b(5k + 2)) = (5k − 2)/(5k + 2). Yahan **b common factor** hai (har term mein), isliye cancel hua.
Right side: (5dk − 2d)/(5dk + 2d) = d(5k − 2)/(d(5k + 2)) = (5k − 2)/(5k + 2).
Dono **(5k − 2)/(5k + 2)** hain, to barabar.
**Jaanch:** a = 15, b = 10, c = 21, d = 14 (15/10 = 21/14 = 3/2): (75 − 20)/(75 + 20) = 55/95 = 11/19 aur (105 − 28)/(105 + 28) = 77/133 = 11/19 ✅.

### Example 5: (a² + b²)/(c² + d²) = ab/(cd)

a = bk, c = dk. Left side: (b²k² + b²)/(d²k² + d²) = b²(k² + 1)/(d²(k² + 1)) = b²/d². Right side: (bk · b)/(dk · d) = b²k/(d²k) = b²/d².
Dono **b²/d²**, to barabar. (Yahan (k² + 1) aur k common **factor** the, isliye cancel hue. Dono kabhi zero nahi, kyunki k ≠ 0 maanna hoga.)
**Jaanch:** a = 12, b = 16, c = 9, d = 12 (12/16 = 9/12 = 3/4): (144 + 256)/(81 + 144) = 400/225 = 16/9 aur ab/(cd) = 192/108 = 16/9 ✅.

**Componendo-dividendo ka ek-line proof (k se).** Topic 2 mein (a + b)/(a − b) = (c + d)/(c − d) saabit kiya tha. k se bhi dekho: a = bk, c = dk: left = b(k + 1)/(b(k − 1)) = (k + 1)/(k − 1) aur right = d(k + 1)/(d(k − 1)) = (k + 1)/(k − 1). Dono barabar, jab k ≠ 1 (yaani a ≠ b). Yahi k-method ki taaqat hai: **ek hi tareeka, sab proof.**

## Part C: Barabar ratio ka jod

Atul ne dekha ki aunty ke dono order ek hi rang ke the, aur jab usne dono order ke laal ko jod kar (21 + 35 = 56) aur peele ko jod kar (9 + 15 = 24) dekha, to 56 : 24 = 7 : 3 phir wahi aaya. **Kyun?**

Maano a/b = c/d = e/f = k. To a = bk, c = dk, e = fk. Jodo: a + c + e = bk + dk + fk = k(b + d + f). Dono taraf (b + d + f) se divide karo (jab b + d + f ≠ 0):

**(a + c + e)/(b + d + f) = k = a/b = c/d = e/f.**

Do ratio ho to e, f hata do: (a + c)/(b + d) = a/b. Ye kisi bhi multiplier ke saath chalta hai: (pa + qc + re)/(pb + qd + rf) = k, kyunki pa + qc + re = k(pb + qd + rf).

Ek aur baat: ye "ghatane" par bhi chalta hai (a − c)/(b − d) = k, par tab b ≠ d chahiye.

**Jaanch:** 4/6 = 10/15 = 14/21 (har ek 2/3). Jod: (4 + 10 + 14)/(6 + 15 + 21) = 28/42 = 2/3 ✅. Multipliers ke saath (2, 3 aur −1): (2 · 4 + 3 · 10 − 14)/(2 · 6 + 3 · 15 − 21) = 24/36 = 2/3 ✅.

### Example 6: unknown ko jod se nikalna

Teen order ek hi shade ke hain. Laal 12 L, 18 L aur 30 L; teeno ka kul peela 45 L hai. Har order mein peela kitna?
Barabar ratio ka jod: (12 + 18 + 30)/(kul peela) = 60/45 = 4/3, to shade **laal : peela = 4 : 3.** Peela = laal × 3/4: 12 × 3/4 = 9, 18 × 3/4 = 13.5, 30 × 3/4 = 22.5 L.
**Story check:** 9 + 13.5 + 22.5 = 45 L kul peela hai, jo diya tha, aur har order mein laal : peela = 12 : 9 = 4 : 3, 18 : 13.5 = 4 : 3, 30 : 22.5 = 4 : 3: teeno orders ek hi rang dete hain.

### Example 7: x/3 = y/5 = z/7 aur ek relation

x/3 = y/5 = z/7 aur 4x − y + 2z = 63. x, y, z?
k lo: x = 3k, y = 5k, z = 7k (**teeno** mein wahi k). 4x − y + 2z = 12k − 5k + 14k = 21k = 63, to k = 3. x = **9**, y = **15**, z = **21.**
**Jaanch:** 4(9) − 15 + 2(21) = 36 − 15 + 42 = 63 ✅, aur 9/3 = 3, 15/5 = 3, 21/7 = 3 ✅.

## Part D: Relation se ratio a : b nikalna

Kabhi ratio diya nahi hota, ek relation diya hota hai aur **a : b** poochha jaata hai. Chaal: a wale terms ek taraf, b wale terms doosri taraf, phir a/b banao. (Ye k-method hai ulti disha mein: a = bk mein k = a/b ko dhoondhna.)

### Example 8: ek rekha wali relation

9a − 4b = 3a + 11b. a : b?
a wale ek taraf: 9a − 3a = 11b + 4b, to 6a = 15b. Dono taraf 6b se divide karo: a/b = 15/6 = **5/2**, yaani a : b = 5 : 2.
**Jaanch:** a = 5, b = 2 lo: 9(5) − 4(2) = 37 aur 3(5) + 11(2) = 37 ✅.

### Example 9: a² wali relation, do jawab

a² + 2b² = 3ab. a : b?
Dono taraf b² se divide karo (b ≠ 0): (a/b)² + 2 = 3(a/b). t = a/b lo: t² − 3t + 2 = 0, yaani (t − 1)(t − 2) = 0, to t = 1 ya t = 2. Do jawab: a : b = **1 : 1** ya **2 : 1.**
**Jaanch:** a = 1, b = 1: 1 + 2 = 3 aur 3 · 1 · 1 = 3 ✅. a = 2, b = 1: 4 + 2 = 6 aur 3 · 2 · 1 = 6 ✅. (Quadratic ke dono root: [Chapter 3](../quadratic-equations/quadratic-equations-part4.md) ki tarah.)

## Part E: Componendo-dividendo se x nikalna

Jab equation mein aisa ratio ho jiska numerator A + B aur denominator A − B ho (A, B mein x ho), to dono taraf ke ratio par componendo-dividendo lagao.

**Kyun?** Agar (A + B)/(A − B) = p/q ho, to Topic 2 ki property se (pehle ko aur doosre ko jod kar aur ghata kar):

((A + B) + (A − B))/((A + B) − (A − B)) = (p + q)/(p − q), yaani 2A/2B = (p + q)/(p − q), to

**A/B = (p + q)/(p − q)** (p ≠ q).

**Jaanch:** A = 5, B = 3: (5 + 3)/(5 − 3) = 4 = p/q, to (4 + 1)/(4 − 1) = 5/3 = A/B ✅.

### Example 10: square root wala

(√(x + 8) + √(x − 8))/(√(x + 8) − √(x − 8)) = 4. x?
A = √(x + 8), B = √(x − 8), p/q = 4/1. Ab A/B = (4 + 1)/(4 − 1) = 5/3. Square karo: (x + 8)/(x − 8) = 25/9, cross-multiply: 9(x + 8) = 25(x − 8), 9x + 72 = 25x − 200, 272 = 16x, **x = 17.**
**Jaanch:** x = 17: x + 8 = 25 aur x − 8 = 9, √25 = 5, √9 = 3. (5 + 3)/(5 − 3) = 8/2 = 4 ✅.

### Example 11: ek jawab galat nikalta hai

(2x + √(4x² − 9))/(2x − √(4x² − 9)) = 9. x?
A = 2x, B = √(4x² − 9), p/q = 9/1: A/B = (9 + 1)/(9 − 1) = 10/8 = 5/4, yaani 2x/√(4x² − 9) = 5/4, to 8x = 5√(4x² − 9). Square karo: 64x² = 25(4x² − 9) = 100x² − 225, to 36x² = 225, x² = 225/36, x = **5/2** ya **−5/2.**
**Jaanch:** x = 5/2: 2x = 5, 4x² − 9 = 25 − 9 = 16, √16 = 4. (5 + 4)/(5 − 4) = 9 ✅. x = −5/2: 2x = −5, √16 = 4: (−5 + 4)/(−5 − 4) = (−1)/(−9) = 1/9, jo 9 nahi hai, to x = −5/2 **radd (reject)** (square karne se ek extra jawab aa gaya; 8x = 5 × (square root) mein right side ≥ 0, to x ≥ 0 chahiye tha). Jawab: **x = 5/2.**

## Part F: Teen terms par k: a/b = b/c

Topic 3 mein a : b = b : c (continued proportion) aur GP mein b² = ac mila tha. k se dono ek jhatke mein: a/b = b/c = k lo. Chhote term c se chalo: **b = ck**, aur **a = bk = ck².** Ab b² = c²k² aur ac = (ck²)(c) = c²k²: dono barabar, **b² = ac.** Aur GP ki zubaan mein: c, ck, ck² ka common ratio k hai (a, b, c ulte order mein likho to ratio 1/k).

```
a = 9 : #########
b = 6 : ######
c = 4 : ####
```

> **Figure 4.2** – a/b = b/c, jahan 9/6 = 6/4 = 3/2 = k. Har agli bar pichhli ki 2/3 guna chhoti hai, yaani c = 4 se b = 4 × 3/2 = 6 aur a = 6 × 3/2 = 9.

### Example 12: (a − b)/(b − c) = a/b

a/b = b/c = k: b = ck, a = ck². a − b = ck² − ck = ck(k − 1). b − c = ck − c = c(k − 1). To (a − b)/(b − c) = ck(k − 1)/(c(k − 1)) = **k** = a/b. (k ≠ 1 chahiye, yaani a ≠ b: nahi to dono taraf zero ho jaata.)
**Jaanch:** a = 9, b = 6, c = 4: (9 − 6)/(6 − 4) = 3/2 aur a/b = 9/6 = 3/2 ✅.

## Aam galtiyan (bachke rehna)

**Galti 1: c ko k mein na badalna, ya dono ratio ke liye alag k lena**

Sawaal: a/b = c/d ho to (a + 2c)/(b + 2d) = a/b dikhao. Ek bachche ne sirf a = bk likha aur c ko waise hi chhod diya: (bk + 2c)/(b + 2d). Ab kuch cancel nahi hota, aur wo ruk gaya. Doosre bachche ne dono ke liye alag letter liya: a = bk, c = dm, aur (bk + 2dm)/(b + 2d) pe pahunchkar bola "alag letter hain, isliye ye k nahi ban sakta."
**Ulta udaharan:** 6/4 = 9/6 lo (dono 3/2). b = 4, d = 6. Agar a = bk (k = 3/2) aur c = dm ke liye alag m = 2 liya jaaye (is m se c = 6 × 2 = 12 ho jaata hai, jo asli 9 nahi hai, yaani ratio hi toot gaya): (4 × 3/2 + 2 × 6 × 2)/(4 + 12) = (6 + 24)/16 = 30/16 = 15/8, jo 3/2 nahi hai. Alag k lene se jawab badal gaya.
Kyun galat? Do ratio barabar hain isliye unki value **ek hi** hai. Sahi: a = bk **aur** c = dk, ek hi k. Tab (bk + 2dk)/(b + 2d) = k(b + 2d)/(b + 2d) = **k** = a/b.
**Jaanch:** isi ek hi k = 3/2 se (6 + 2 × 9)/(4 + 2 × 6) = 24/16 = 3/2, aur a/b = 6/4 = 3/2 ✅. (Wahi 6/4 = 9/6 aur k = 3/2 jo upar liye the.)

**Galti 2: Sum mein common TERM cancel karna, common FACTOR nahi**

Sawaal: a/b = 6/5 ho to (5a + 3b)/(a + 3b) ki value. Ek bachche ne dekha ki upar aur neeche dono mein "+ 3b" hai aur use kaatkar likha: (5a)/(a) = **5.** **Ulta udaharan:** a = 6, b = 5 (6 : 5): (30 + 15)/(6 + 15) = 45/21 = 15/7, jo 5 nahi hai.
Kyun galat? 3b ek **term** hai (jod ka ek hissa), poore numerator aur denominator ka **factor** nahi. Sirf wo cheez cancel hoti hai jisse **poora** numerator aur **poora** denominator guna hua ho. Sahi: a = 6k, b = 5k lo: (30k + 15k)/(6k + 15k) = 45k/(21k). Yahan k poore numerator aur poore denominator ka **factor** hai, isliye cancel hota hai: 45/21 = **15/7.**
**Jaanch:** a = 6, b = 5: 45/21 = 15/7 ✅ (wahi numbers jo upar ulta udaharan mein the).

## Quick Recap

- a/b = c/d ka matlab dono ratio ki **ek hi value k**: a = bk, c = dk. **Dono** badlo, **ek hi k** rakho.
- k-method ad = bc ka hi doosra roop hai: ad = bdk = bc. k aksar fraction hota hai.
- **Proof ki chaal:** k lo, a aur c dono ko substitute karo, common **factor** cancel karo, dono side barabar dikhao, phir number se check.
- **Barabar ratio ka jod:** a/b = c/d = e/f ho to (a + c + e)/(b + d + f) = a/b (jab b + d + f ≠ 0), aur multipliers ke saath bhi: (pa + qc + re)/(pb + qd + rf) = k.
- **Relation se a : b:** a wale ek taraf, b wale doosri taraf, a/b banao. a² wali relation mein b² se divide karke quadratic in a/b.
- **(A + B)/(A − B) = p/q** se **A/B = (p + q)/(p − q)** (p ≠ q). Square karne par aaye jawab ko wapas daalkar jaancho (extra root radd).
- Teen terms: a/b = b/c = k to b = ck, a = ck², aur b² = ac.
- Galtiyan: sirf ek ratio mein k lagana (ya do alag k); sum mein common term cancel karna.

## Practice Questions

4. Find a : b if 6a² + 15b² = 19ab. (Two answers.)
5. If x/4 = y/7 = z/9 and 2x + y − z = 30, find x, y and z.
6. Three batches of green paint are the same shade. They use 15 L, 25 L and 40 L of blue, and the three batches use 96 L of white in all. How much white is in each batch? Check with a story check.
7. Solve (√(2x + 3) + √(2x − 3))/(√(2x + 3) − √(2x − 3)) = 3.
8. If (2a + 3b)/(2a − 3b) = 11/5, find a : b.
9. If a/b = b/c, prove that (2a + 3b)/(2b + 3c) = a/b. Check it with a = 25, b = 15, c = 9.
10. If x : y = 5 : 9, find the value of (7x − 2y)/(3x + 4y).
11. A shop mixes yellow and white paint. Batch 1 uses 24 L of yellow and 56 L of white. Batch 2 uses 15 L of yellow and 35 L of white. Show that both batches are the same shade, and find the ratio of yellow to white in the two batches put together.
12. True or false (give a reason or a counter-example):
 (a) If a/b = c/d = k, then a + c = k(b + d).
 (b) If 4/7 = 12/21, then (4 + 3)/(7 + 3) = (12 + 3)/(21 + 3).
 (c) If a/b = c/d, you may use k for the first ratio and any other letter for the second ratio and still prove an identity.

### Answers

**1.** a/b = c/d = k, a = bk, c = dk. Left side: (5b²k² − 2d²k²)/(5b² − 2d²) = k²(5b² − 2d²)/(5b² − 2d²) = k². Right side: a²/b² = b²k²/b² = k². Barabar.
**Jaanch:** a = 6, b = 9, c = 10, d = 15 (6/9 = 10/15 = 2/3): (5 × 36 − 2 × 100)/(5 × 81 − 2 × 225) = (180 − 200)/(405 − 450) = (−20)/(−45) = 4/9 aur a²/b² = 36/81 = 4/9 ✅.

**2.** a = bk, c = dk. Left: (bk + 3b)/(dk + 3d) = b(k + 3)/(d(k + 3)) = b/d. Right: (bk − 2b)/(dk − 2d) = b(k − 2)/(d(k − 2)) = b/d. Barabar (k ≠ −3, 2).
**Jaanch:** a = 10, b = 4, c = 15, d = 6 (k = 5/2): (10 + 12)/(15 + 18) = 22/33 = 2/3 aur (10 − 8)/(15 − 12) = 2/3 ✅ (b/d = 4/6 = 2/3).

**3.** 7a − 2a = 7b + 5b, to 5a = 12b, a/b = 12/5, **a : b = 12 : 5.**
**Jaanch:** a = 12, b = 5: 7(12) − 5(5) = 84 − 25 = 59 aur 2(12) + 7(5) = 24 + 35 = 59 ✅.

**4.** b² se divide karo, t = a/b: 6t² − 19t + 15 = 0, (2t − 3)(3t − 5) = 0 (kyunki 6t² − 10t − 9t + 15), to t = 3/2 ya 5/3. **a : b = 3 : 2** ya **5 : 3.**
**Jaanch:** a = 3, b = 2: 6(9) + 15(4) = 54 + 60 = 114 aur 19(6) = 114 ✅. a = 5, b = 3: 6(25) + 15(9) = 150 + 135 = 285 aur 19(15) = 285 ✅.

**5.** x = 4k, y = 7k, z = 9k. 2x + y − z = 8k + 7k − 9k = 6k = 30, k = 5. **x = 20, y = 35, z = 45.**
**Jaanch:** 2(20) + 35 − 45 = 30 ✅ aur 20/4 = 35/7 = 45/9 = 5 ✅.

**6.** Blue ka jod 15 + 25 + 40 = 80 L, kul white 96 L, to blue : white = 80 : 96 = 5 : 6. White = blue × 6/5: 15 × 6/5 = 18 L, 25 × 6/5 = 30 L, 40 × 6/5 = 48 L.
**Story check:** 18 + 30 + 48 = 96 L kul white hai, jo diya tha, aur 15 : 18 = 25 : 30 = 40 : 48 = 5 : 6: teeno batch ek hi shade.

**7.** A/B = √(2x + 3)/√(2x − 3) = (3 + 1)/(3 − 1) = 2. Square: (2x + 3)/(2x − 3) = 4, to 2x + 3 = 8x − 12, 15 = 6x, **x = 5/2.**
**Jaanch:** 2x = 5: √8 aur √2. √8 = 2√2, to (2√2 + √2)/(2√2 − √2) = 3√2/√2 = 3 ✅.

**8.** Componendo-dividendo: 2a/3b = (11 + 5)/(11 − 5) = 16/6 = 8/3, to a/b = (8/3) × (3/2) = 4. **a : b = 4 : 1.**
**Jaanch:** a = 4, b = 1: (8 + 3)/(8 − 3) = 11/5 ✅.

**9.** a/b = b/c = k, b = ck, a = ck². Left: (2ck² + 3ck)/(2ck + 3c) = ck(2k + 3)/(c(2k + 3)) = k = a/b.
**Jaanch:** a = 25, b = 15, c = 9 (25/15 = 15/9 = 5/3): (50 + 45)/(30 + 27) = 95/57 = 5/3 aur a/b = 25/15 = 5/3 ✅.

**10.** x = 5k, y = 9k. (35k − 18k)/(15k + 36k) = 17k/(51k) = 17/51 = **1/3.**
**Jaanch:** x = 5, y = 9: (35 − 18)/(15 + 36) = 17/51 = 1/3 ✅.

**11.** Batch 1: 24/56 = 3/7, Batch 2: 15/35 = 3/7. Dono ratio barabar, to ek hi shade. Jod: (24 + 15)/(56 + 35) = 39/91 = 3/7, yaani **yellow : white = 3 : 7.**
**Story check:** 24 : 56 aur 15 : 35 dono 3 : 7 hain aur jodne par bhi 39 : 91 = 3 : 7 hai: shade nahi badla.

**12.** (a) **Sahi** ✅: a = bk, c = dk, a + c = k(b + d). (b) **Galat** ❌: 4/7 = 12/21 sahi hai (12/21 = 4/7), par (4 + 3)/(7 + 3) = 7/10 aur (12 + 3)/(21 + 3) = 15/24 = 5/8, jo barabar nahi. Dono terms mein ek hi number jodna ratio nahi rakhta; guna hi ratio rakhta hai. (c) **Galat** ❌: c = dm mein m alag rakhne se dono ratio ka rishta toot jaata hai; ek hi k lena padta hai kyunki dono ratio ki value ek hi hai.
