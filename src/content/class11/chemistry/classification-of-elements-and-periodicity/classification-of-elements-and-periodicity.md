## Part A: Mendeleev se Modern Periodic Law — Moseley ka X-Ray Saboot (1913)

Class 9 ([periodic-table-part2.md](../../../class9/chemistry/periodic-table/periodic-table-part2.md)) mein humne dekha tha ki Mendeleev (1869) ne tatvon ko **atomic mass** ke kram mein sajaya tha aur Eka-aluminium (Gallium) tatha Eka-silicon (Germanium) ki shaandar bhavishyavani ki thi — par isotopes aur Ar/K jaise ulti-mass jodon par unka table atak gaya.

1913 mein **Henry Moseley** ne alag-alag tatvon par tez electrons maar kar unse nikalne wali X-rays ki frequency (ν) naapi *(sirf padhne ke liye; X-rays khatarnak radiation hain)*. Unhone do graphs banaye:
- **√ν banaam Atomic Mass (A):** Rekha tedhi-medhi aayi!
- **√ν banaam Atomic Number (Z):** Bilkul **ekdam seedhi rekha (straight line)** aayi: **√ν = a(Z − b)**!

```
   √ν (X-ray frequency ka square root)
    ^
    :               /
    :             /   <-- √ν vs Atomic Number (Z): SEEDHI REKHA!
    :           /         (Isne sabit kiya ki Z hi asli pehchaan hai!)
    :         /
    +------------------> Z (Atomic Number)
```

> **Figure 1.1** – Moseley ka X-ray plot: √ν ko atomic number (Z) ke saath plot karne par exact seedhi rekha milti hai, jabki atomic mass ke saath nahi.

Isi se **Modern Periodic Law** bana:
> **Tatvon ke physical aur chemical gun unke atomic numbers (Z) ke periodic functions hote hain.**
*(Aur kyunki neutral atom mein Z = protons = electrons, isliye periodicity ka asli kaaran **outermost electronic configuration ka baar-baar dohraana** hai!)*

### Mendeleev banaam Modern Periodic Table — Ek Nazar Mein

| Feature | Mendeleev's Table (1869) | Modern Periodic Table (Moseley, 1913) |
|---|---|---|
| **Aadhaar (Basis)** | Badhta hua **Atomic Mass (A)** | Badhta hua **Atomic Number (Z)** |
| **Isotopes ki jagah** | Alag mass hone se jagah tay nahi thi | Same Z hone se sabhi isotopes **ek hi box** mein! |
| **Anomalous pairs (Ar/K, Co/Ni, Te/I)** | Mass ka kram todna pada tha | Atomic number ke kram mein **khud sahi jagah** aa gaye! |
| **Rows aur Columns** | 7 Periods, 8 Groups (A/B) | 7 Periods, **18 Vertical Groups** (s, p, d, f blocks) |

### Magic Numbers (2, 8, 8, 18, 18, 32, 32) ka Raaz
Har period mein kitne elements aayenge, ye seedha us period mein bharne wale **subshells ki capacity** se tay hota hai:
- Period 1: 1s → **2**; Period 2: 2s + 2p → **8**; Period 3: 3s + 3p → **8**; Period 4: 4s + 3d + 4p → **18**; Period 5: 5s + 4d + 5p → **18**; Period 6: 6s + 4f + 5d + 6p → **32**; Period 7: 7s + 5f + 6d + 7p → **32**!

## Part B: Z > 100 Tatvon Ka IUPAC Systematic Nomenclature

Jab Z = 104 khoja gaya, to ek team ne use *Rutherfordium* aur doosri team ne *Kurchatovium* kehna shuru kar diya! Is uljhan ko khatam karne ke liye **IUPAC (International Union of Pure and Applied Chemistry)** ne 1978 mein ek aasaan, universal temporary naming rule banaya:

### 0 se 9 tak ke IUPAC Digit Roots

| Digit | Root | Abbreviation (1 letter) | Digit | Root | Abbreviation (1 letter) |
|---|---|---|---|---|---|
| **0** | nil | n | **5** | pent | p |
| **1** | un | u | **6** | hex | h |
| **2** | bi | b | **7** | sept | s |
| **3** | tri | t | **8** | oct | o |
| **4** | quad | q | **9** | enn | e |

### Naam aur Symbol Banane ke 3 Kadam (+ 2 Spelling Rules!)
1. Atomic number Z ke teeno digits ke roots ko kram se jodo (pehla akshar Capital).
2. Aakhir mein **-ium** lagao.
3. Har digit ke 1-letter abbreviation ko jodkar **3-letter symbol** banao (pehla akshar Capital, baaki do small).
4. **Do zaroori spelling (elision) rules:**
   - **Rule 1:** Agar root **bi** ya **tri** ke theek baad **-ium** aaye, to do 'i' (ii) ek saath nahi likhte — ek 'i' hata do! (**bi + ium → bium**, **tri + ium → trium**).
   - **Rule 2:** Agar **enn** (9) ke theek baad **nil** (0) aaye, to teen 'n' (nnn) ek saath nahi likhte — ek 'n' hata do! (**enn + nil → ennil**).

### Example 1. Z = 104, 112, 119 aur 120 ke IUPAC Naam aur Symbols

**Sawaal:** Atomic numbers **104, 112, 119 aur 120** ke IUPAC systematic names aur 3-letter symbols likho.

**Hal:**
- **Z = 104 (1-0-4):** un + nil + quad + ium = **Unnilquadium**, Symbol = **Unq** *(Permanent official IUPAC name: Rutherfordium, Rf)*.
- **Z = 112 (1-1-2):** un + un + bi + ium → elision se ek 'i' hata → **Ununbium**, Symbol = **Uub** *(Permanent official IUPAC name: Copernicium, Cn)*.
- **Z = 119 (1-1-9):** un + un + enn + ium = **Ununennium**, Symbol = **Uue** *(Abhi khoja jaana baaki hai!)*.
- **Z = 120 (1-2-0):** un + bi + nil + ium = **Unbinilium**, Symbol = **Ubn**.

**Jaanch:** Har symbol mein theek 3 letters hain (Unq = 1-0-4, Uub = 1-1-2, Uue = 1-1-9, Ubn = 1-2-0) aur Z = 112 mein "biium" ki jagah "bium" likha gaya hai ✅.

### Example 2. Symbol se Z Nikalna aur Elision Check

**Sawaal:** In teen IUPAC symbols se atomic number **Z** aur poora systematic naam likho: (a) **Unt**, (b) **Uus**, (c) **Uen** (kalpanik).

**Hal:**
- (a) **Unt** = u(1) − n(0) − t(3) → **Z = 103** → un + nil + tri + ium → elision (tri + ium → trium) → **Unniltrium** *(Official: Lawrencium, Lr)*.
- (b) **Uus** = u(1) − u(1) − s(7) → **Z = 117** → un + un + sept + ium → **Ununseptium** *(Official: Tennessine, Ts)*.
- (c) **Uen** = u(1) − e(9) − n(0) → **Z = 190** → un + enn + nil + ium → elision (enn + nil → ennil) → **Unennilium**.

**Jaanch:** 1-0-3 (Unt), 1-1-7 (Uus), 1-9-0 (Uen); kahin bhi "ii" ya "nnn" nahi aaya ✅.

## Aam galtiyan (bachke rehna)

1. **Galti 1: Z = 102 ya 112 mein "biium" aur Z = 103 ya 113 mein "triium" likh dena.**
   *Sahi baat:* Do 'i' ek saath nahi aate! Sahi spelling **Unnilbium (Unb)**, **Ununbium (Uub)**, **Unniltrium (Unt)** aur **Ununtrium (Uut)** hai.

2. **Galti 2: 9 aur 0 saath aane par "ennnil" likh dena.**
   Z = 190 (kalpanik udhaharan) mein un + enn + nil + ium jodte waqt teen 'n' ban jaate hain.
   *Sahi baat:* Ek 'n' hatakar **Unennilium (Uen)** likha jaata hai!

3. **Galti 3: Moseley ke plot ko "ν vs Z" likh dena.**
   Seedhi rekha frequency ν ke saath nahi, balki **√ν (square root of frequency)** banaam **Z** ke saath milti hai!

## Quick Recap

- **Moseley (1913):** √ν = a(Z − b) ki seedhi rekha ne **Modern Periodic Law** (properties = periodic function of Z) diya.
- **IUPAC Nomenclature (Z > 100):** 0=nil, 1=un, 2=bi, 3=tri, 4=quad, 5=pent, 6=hex, 7=sept, 8=oct, 9=enn + **-ium**; 3-letter symbol.
- **Elision rules:** bi + ium → **bium**; tri + ium → **trium**; enn + nil → **ennil**.
