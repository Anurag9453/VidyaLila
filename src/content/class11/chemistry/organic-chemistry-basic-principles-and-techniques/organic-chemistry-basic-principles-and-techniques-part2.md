Par Class 11 mein asli challenges aate hain: jab ek hi molecule mein **do ya teen functional groups** (jaise −COOH aur −OH, ya −CHO aur C=O) ek saath hon, ya jab **benzene ring** par 3 alag groups lage hon! ## Kalpana aur bade library ka 5-hisson wala shelf code

Kalpana school ki nayi digital library mein books arrange kar rahi thi. Har book par ek **5-piece code** tha:
- **Branch tags** (chhote stickers) → **Secondary Prefix** (substituents: chloro, methyl, hydroxy)
- **Ring tag** (agar special circular rack ho) → **Primary Prefix** (*cyclo-*)
- **Main shelf length** → **Word Root** (meth, eth, prop, but, pent, hex...)
- **Saturation** → **Primary Suffix** (*-ane, -ene, -yne*)
- **VIP Section (sabse bada Boss!)** → **Secondary Suffix** (*-oic acid, -al, -one, -ol*)

Kalpana ne muskurate hue kaha, "Agar kisi book mein 2 categories hon, to wo **VIP Priority List** wale section mein jaati hai aur doosri category bas chhote sticker (prefix) par likh di jaati hai!" Teacher ma'am ne taali bajayi: "Kalpana, yahi **Polyfunctional IUPAC Nomenclature** ka sabse bada niyam hai!"

## Part A: 5-Piece IUPAC Formula aur Priority Table (Yaad Rakhne ki Master List!)

> **IUPAC Name = Secondary Prefix + Primary Prefix (cyclo) + Word Root + Primary Suffix (ane/ene/yne) + Secondary Suffix (Principal FG)**

### Functional Group Priority Order (Upar = Sabse Bada Boss!)

| Priority | Functional Group | **Prefix (jab Boss NA ho)** | **Suffix (jab Boss HO)** |
|---|---|---|---|
| **1 (Boss!)** | **−COOH** (Carboxylic acid) | carboxy- | **-oic acid** |
| **2** | **−SO₃H** (Sulphonic acid) | sulpho- | **-sulphonic acid** |
| **3** | **−COOR** (Ester) | alkoxycarbonyl- | **-oate** |
| **4** | **−COCl** (Acid chloride) | chlorocarbonyl- | **-oyl chloride** |
| **5** | **−CONH₂** (Amide) | carbamoyl- | **-amide** |
| **6** | **−CN** (Nitrile) | cyano- | **-nitrile** |
| **7** | **−CHO** (Aldehyde) | formyl- / oxo- | **-al** |
| **8** | **>C=O** (Ketone) | **oxo-** | **-one** |
| **9** | **−OH** (Alcohol) | **hydroxy-** | **-ol** |
| **10** | **−NH₂** (Amine) | **amino-** | **-amine** |
| **11–12** | **C=C** > **C≡C** | — | **-ene**, **-yne** |
| **Hamesha Prefix!** | **−F, −Cl, −Br, −I, −NO₂, −OR, −R** | fluoro-, chloro-, bromo-, iodo-, nitro-, alkoxy-, alkyl- | *(Kabhi suffix nahi bante!)* |

**3 Golden Numbering Rules:**
1. **Longest continuous chain** chuno jismein **Principal Functional Group** (aur maximum multiple bonds) shamil hon!
2. **Lowest Set of Locants:** Principal FG ko sabse chhota number do; tie hone par **First Point of Difference** dekho (kabhi sirf "lowest sum" mat lagao!).
3. **Alphabetical Order:** Substituents likhte waqt **di-, tri-, tetra-, sec-, tert-** ko ignore karo (**ethyl** pehle **dimethyl** se!), par **iso-** aur **neo-** ko alphabet mein gino!
4. **Vowel Drop Rule:** Jab secondary suffix vowel (**a, e, i, o, u**) se shuru ho (jaise -ol, -al, -one, -oic acid), to primary suffix ka aakhiri **'e'** hata do (e.g. *butan-2-ol*, *but-3-en-1-ol*); par consonant se shuru ho (jaise -diol, -nitrile) to 'e' rakho (*ethane-1,2-diol*)!

## Part B: Substituted Benzene Compounds ke Niyam

- **Common IUPAC-Accepted Parent Names:** **Toluene** (CH₃), **Phenol** (OH), **Aniline** (NH₂), **Anisole** (OCH₃), **Benzaldehyde** (CHO), **Benzoic acid** (COOH), **Nitrobenzene** (NO₂).
- Jab benzene par koi parent-name group (jaise −OH in phenol ya −COOH in benzoic acid) laga ho, to us Carbon ko hamesha **Position 1** milti hai!
- Jab sirf prefix-only groups (jaise −Br, −Cl, −NO₂) lage hon, to lowest set of locants lagao; tie hone par **alphabetical order** mein pehle aane wale group ko **1** do (jaise **1-bromo-3-chlorobenzene**)!

## Solved Examples

### Example 1. Branched Alkanes — Lowest Set of Locants & Alphabetical Order

**Sawaal:** Sahi IUPAC naam likho:
(a) **(CH₃)₃C−CH₂−CH(CH₃)₂**
(b) **CH₃−CH(CH₃)−CH(C₂H₅)−CH₂−CH₂−CH₃**

**Hal:**
- (a) Longest chain = **5 C (pentane)**. Left se numbering: **2,2,4**; Right se: 2,4,4. First point of difference par 2 = 2, phir **2 < 4** → Left sahi!
  - Naam: **2,2,4-trimethylpentane**!
- (b) Longest chain = **6 C (hexane)**; C2 par methyl, C3 par ethyl. Alphabetical order mein **ethyl** pehle, **methyl** baad mein!
  - Naam: **3-ethyl-2-methylhexane**!

**Jaanch:** (a) 2,2,4 < 2,4,4 ✅; (b) 'e' before 'm' ✅.

---

### Example 2. Polyfunctional Compounds (Priority Table ka Kamaal!)

**Sawaal:** IUPAC naam likho:
(a) **CH₃−CO−CH₂−COOH**
(b) **CH₃−CH(OH)−CH₂−CO−CH₃**
(c) **CH₃−CH(CH₃)−CH₂−CH(Cl)−COOH**

**Hal:**
- (a) Boss: **−COOH** (C1!) > ketone C=O (C3 par prefix = **oxo-**). 4 C chain → **3-oxobutanoic acid**!
- (b) Boss: **>C=O** (C2!) > alcohol −OH (C4 par prefix = **hydroxy-**). 5 C chain → **4-hydroxypentan-2-one**!
- (c) Boss: **−COOH** (C1!), C2 par chloro, C4 par methyl ('c' pehle 'm' se!) → **2-chloro-4-methylpentanoic acid**!

**Jaanch:** Har molecule mein priority table ka Boss C1 ya sabse chhote number par hai ✅.

---

### Example 3. Substituted Benzene Compounds

**Sawaal:** IUPAC naam likho:
(a) Benzene ring par C1 par −NO₂, C2 par −Br, C4 par −Cl.
(b) Benzene ring par C1 par −OH, C2 par −CH₃, C4 par −Cl.

**Hal:**
- (a) Teeno prefix groups hain; lowest locants = **1,2,4** (agar Cl ko 1 dein to 1,3,4 bada hai; Br ko 1 dein to 1,2,5 bada hai — wait: **Br at 2, NO₂ at 1, Cl at 4 → 1,2,4**; aur agar Br ko 1 dein, NO₂ ko 2, Cl ko 5 → 1,2,5 > 1,2,4! Isliye NO₂ = 1, Br = 2, Cl = 4!). Alphabetical likho: **2-bromo-4-chloro-1-nitrobenzene** (ya **2-bromo-4-chloronitrobenzene**)!
- (b) −OH parent **phenol** (C1!), C2 par methyl, C4 par chloro → alphabetical: **4-chloro-2-methylphenol**!

**Jaanch:** 1,2,4 < 1,2,5 aur alphabetical order 'b' < 'c' < 'n' ✅.

## Aam galtiyan (bachke rehna)

1. **Galti 1: Lowest Sum Rule laga kar 3,4,9 (sum 16) ko 2,7,8 (sum 17) se behtar maan lena!**
   *Sahi baat:* IUPAC **First Point of Difference (Lowest Set of Locants)** use karta hai: pehla digit **2 < 3**, isliye **2,7,8** sahi hai!

2. **Galti 2: Alphabetical order mein "dimethyl" ka 'd' dekh kar use "ethyl" se pehle likh dena!**
   *Sahi baat:* Prefixes **di-, tri-, tetra-** alphabetical order mein **NAHI** gine jaate! Compare karo **'e' (ethyl)** vs **'m' (methyl)** → **3-ethyl-2,2-dimethyl...**!

3. **Galti 3: Double bond ya halogen ko −COOH / −CHO / −OH se zyada priority de dena!**
   Hamesha Priority Table dekho: **−COOH > −CHO > >C=O > −OH > −NH₂ > C=C > C≡C > −X/−NO₂**!

## Quick Recap

- **5-Piece Formula:** Secondary Prefix + Primary Prefix + Word Root + Primary Suffix + Secondary Suffix.
- **Boss Priority:** −COOH > −SO₃H > −COOR > −COCl > −CONH₂ > −CN > −CHO > >C=O > −OH > −NH₂ > C=C > C≡C > −X/−NO₂/−OR.
- **Lowest Set of Locants** (first point of difference); ignore **di/tri/sec/tert** in alphabetising.
- **Benzene:** 1,2 = *o*, 1,3 = *m*, 1,4 = *p*; parent group (−OH, −COOH, −CHO, −NH₂) hamesha **C1**!

## Practice Questions

   (a) **CH₃−CH(CH₃)−C≡CH**
   (b) **CH₃−CH=CH−C≡CH** *(Hint: when C=C and C≡C get identical locants from both ends, double bond gets lower number; here C≡C gets 1!)*
   (c) **CH₃−CH(OH)−CH₂−CHO**
   (d) **CH₃−CH(NH₂)−COOH**
2. Write the correct IUPAC names for these cyclic and aromatic compounds:
   (a) Cyclohexane ring with **−Cl at C1** and **−CH₃ at C3**

3. Draw (write condensed structural formulas for) the following IUPAC names:
   (a) **4-ethyl-2,3-dimethylheptane**
   (b) **hex-4-en-2-ol**
   (c) **2-methylpropanal**
   (d) **pentane-2,4-dione**
4. Each of the following IUPAC names is **INCORRECT**. Draw its structure, find the mistake, and write the **correct IUPAC name**:
   (a) **2-ethylpentane**
   (b) **3-methylbutan-2-ol** *(check numbering!)*
   (c) **4-chloro-2-methylpentane**
5. Arrange the following functional groups in **decreasing order of IUPAC priority**: **−OH, −COOH, −CHO, >C=O, −NH₂, −CN**.
6. Name the compound **CH₂=CH−CH₂−C≡CH** carefully! When a double bond and a triple bond are at **identical positions (1 and 4)** from the two ends, which one gets position **1**?
7. Write the IUPAC name of **HO−CH₂−CH₂−OH** (ethylene glycol) and explain why the **'e'** of *ethane* is **NOT dropped** in its name!
8. Give the IUPAC name and molecular formula of (a) **Anisole** (methoxybenzene), (b) **Toluene** (methylbenzene), and (c) **Acetone**.
9. Why is **2,2,4-trimethylpentane** numbered 2,2,4 instead of 2,4,4? State the exact IUPAC rule used.
10. Write the IUPAC name of **CH₃−CO−CH₂−CH₂−COOH**, identifying which group is written as a prefix and which as a suffix.
11. For a disubstituted benzene ring with **−Br** and **−Cl** at positions 1 and 4, write both its systematic IUPAC name and its *o/m/p* name.
12. State whether each statement is True or False, and correct the false ones:
    (a) In alphabetical ordering of substituents, *dimethyl* comes before *ethyl*.
    (b) In 3-hydroxybutanoic acid, −COOH is the principal functional group.
    (c) Halogens (−F, −Cl, −Br, −I) and nitro (−NO₂) groups are always written as prefixes in IUPAC names.
    (d) In a compound containing both −OH and −CHO, −OH gets priority over −CHO.

### Answers

1. (a) **3-methylbut-1-yne** (C≡C ko C1 mila!).
   (b) **pent-3-en-1-yne** (C≡C ko C1 mila: 1,3 < 2,4!).
   (c) **3-hydroxybutanal** (−CHO = C1!).
   (d) **2-aminopropanoic acid** (−COOH = C1!).

2. (a) **1-chloro-3-methylcyclohexane** (tie 1,3 → alphabetical 'c' < 'm'!).
   (b) **3-nitrobenzoic acid** (ya *m*-nitrobenzoic acid).
   (c) **2,4,6-tribromophenol**.

3. (a) **CH₃−CH(CH₃)−CH(CH₃)−CH(C₂H₅)−CH₂−CH₂−CH₃**
   (b) **CH₃−CH=CH−CH₂−CH(OH)−CH₃**
   (c) **CH₃−CH(CH₃)−CHO**
   (d) **CH₃−CO−CH₂−CO−CH₃**

4. (a) **2-ethylpentane** mein longest chain 5 nahi, **6 carbons** ki hai → sahi naam: **3-methylhexane**!
   (b) **3-methylbutan-2-ol** sahi hai (OH ko C2 mila; ulta karne par OH ko C3 milta — Jaanch: 2 < 3 ✅!).
   (c) **4-chloro-2-methylpentane:** dono taraf se locants 2,4 tie hain → alphabetical order mein **chloro** ('c') ko 2 milna chahiye → sahi naam: **2-chloro-4-methylpentane**!

5. Decreasing priority: **−COOH > −CN > −CHO > >C=O > −OH > −NH₂**.

6. **pent-1-en-4-yne**! Jab double bond aur triple bond dono siron se barabar number (1,4) par aayein, to alphabetical priority se **double bond (-ene)** ko number **1** milta hai!

7. **ethane-1,2-diol**. Kyunki secondary suffix **-diol** consonant **'d'** se shuru hota hai (vowel se nahi), isliye *ethane* ka aakhiri **'e'** nahi hataya jaata!

8. (a) **Methoxybenzene** (C₇H₈O); (b) **Methylbenzene** (C₇H₈); (c) **Propan-2-one / Propanone** (C₃H₆O).

9. **First Point of Difference (Lowest Set of Locants):** 2,2,4 aur 2,4,4 ki tulna mein pehla digit barabar (2 = 2), par doosra digit **2 < 4** → isliye 2,2,4 sahi hai!

10. **4-oxopentanoic acid**. **−COOH** principal group hai (suffix: *-oic acid*), aur **>C=O** kam priority par hai (prefix: *oxo-*).

11. **1-bromo-4-chlorobenzene** (alphabetical 'b' gets 1!) ya ***p*-bromochlorobenzene**.

12. (a) **False** ❌. 'di' ignore hota hai → **ethyl** ('e') pehle **dimethyl** ('m') se aata hai!
    (b) **True** ✅.
    (c) **True** ✅.
    (d) **False** ❌. **−CHO** ki priority **−OH** se upar hai!
