# Topic 2: Types of Redox Reactions: Combination, Decomposition, Displacement, Disproportionation aur Comproportionation

Topic 1 mein humne seekha ki har redox reaction mein kisi ek atom ka Oxidation Number (ON) badhta hai aur kisi doosre ka ghat-ta hai. Par kya **har** chemical reaction (jaise CaCO₃ ka tootna ya BaCl₂ + Na₂SO₄ precipitation) redox hota hai? **Bilkul nahi!** Aaj hum redox reactions ke **chaar mukhya prakar** — khaas kar **Halogen Displacement** aur **Disproportionation** (jahan EK HI tatva ek saath oxidise bhi hota hai aur reduce bhi!) — ko poori gehraai se seekhenge!

---

## Madhav aur khel ke maidan ke chaar alag-alag khel

Madhav shaam ko maidan mein chaar alag khel chalte dekh raha tha:
1. Do chhote groups milkar ek badi team ban gaye (**Combination**).
2. Ek badi team tootkar do chhoti teams mein bant gayi (**Decomposition**).
3. Cricket mein ek naye tez player ne purane player ki jagah le li (**Displacement**).
4. Aur ek mazedaar coin-toss khel mein **ek hi khiladi** ke paas 10 points the — ek hissa badhkar 15 ho gaya aur doosra hissa ghatkar 5 ho gaya (**Disproportionation**)!

Teacher ma'am ne muskurate hue kaha, "Madhav, Chemistry mein redox reactions bhi theek inhi **chaar prakar** ke hote hain — bas ek shart pakki honi chahiye: **Oxidation Number zaroor badalna chahiye!**" Chalo, chaaron prakar aur unke saare exceptions dekhte hain.

## Naye shabd

| Shabd | Matlab (simple bhasha mein) | Example |
|---|---|---|
| **Combination redox** | Do ya zyada species (kam se kam ek **elemental form** mein!) judkar ek compound banayein: A + B → C | C(s) + O₂(g) → CO₂(g); 3Mg + N₂ → Mg₃N₂ |
| **Decomposition redox** | Ek compound tootkar do ya zyada products banaye jinmein kam se kam ek **elemental form** mein ho | 2KClO₃ → 2KCl + 3O₂ *(CaCO₃ → CaO + CO₂ redox NAHI hai!)* |

| **Disproportionation** | Wo khaas redox reaction jismein **EK HI tatva** (beech ke intermediate ON mein) ek saath **oxidise (ON ↑)** bhi ho aur **reduce (ON ↓)** bhi! | 2H₂O₂ (−1) → 2H₂O (−2) + O₂ (0) |
| **Comproportionation** | Disproportionation ka theek ulta — ek hi tatva ke do alag ON wale species milkar beech ka ek common ON banayein! | IO₃⁻ (+5) + 5I⁻ (−1) + 6H⁺ → 3I₂ (0) + 3H₂O |

## Part A: Chaar Mukhya Types of Redox Reactions

### 1. Combination Redox Reactions (A + B → C)
Redox hone ke liye A ya B mein se kam se kam ek **elemental state (ON = 0)** mein hona chahiye!
- **C(0) + O₂(0) → CO₂(+4, −2)** (Redox! C oxidised, O reduced)
- **3Mg(0) + N₂(0) → Mg₃N₂(+2, −3)** (Redox!)
- *(Dhyan do: **CaO + CO₂ → CaCO₃** combination to hai, par Ca(+2), C(+4), O(−2) kisi ka ON nahi badla → **NOT redox!**)*

### 2. Decomposition Redox Reactions (AB → A + B)
- **2H₂O(+1, −2) → 2H₂(0) + O₂(0)** (Redox!)
- **2KClO₃(+5, −2) → 2KCl(−1) + 3O₂(0)** (Redox! Cl reduced +5→−1, O oxidised −2→0)
- **NON-REDOX DECOMPOSITION (Classic Trap!):** **CaCO₃(+2, +4, −2) → CaO(+2, −2) + CO₂(+4, −2)** — kisi bhi atom ka ON nahi badla → **Redox NAHI hai!**

### 3. Displacement Redox Reactions (X + YZ → XZ + Y)
Ye do prakar ke hote hain:
- **(a) Metal Displacement:** Zyada reactive metal kam reactive metal ko uske salt se hata deta hai (Class 10 [metals-and-non-metals-part4.md](../../../class10/chemistry/metals-and-non-metals/metals-and-non-metals-part4.md)):
  - **Zn(s) + CuSO₄(aq) → ZnSO₄(aq) + Cu(s)**; **TiCl₄ + 2Mg → Ti + 2MgCl₂** (Kroll process!).
- **(b) Non-Metal Displacement:**
  - **Hydrogen displacement:** Active metals paani ya dilute acid se H₂ nikalte hain (**2Na + 2H₂O → 2NaOH + H₂**; **Zn + 2HCl → ZnCl₂ + H₂**; *Na reaction sirf teacher demo!*).
  - **Halogen displacement (Super-Important!):** Halogens ki oxidising power upar se neeche ghat-ti hai:
    > **Oxidising Power: F₂ > Cl₂ > Br₂ > I₂**
    - Isliye **Cl₂** bromide (Br⁻) aur iodide (I⁻) ko displace kar sakta hai (**Cl₂ + 2KBr → 2KCl + Br₂**), **Br₂** sirf iodide (I⁻) ko displace kar sakta hai, par **I₂ kisi ko displace nahi kar sakta**! *(F₂ itna tez oxidiser hai ki paani se hi O₂ nikaal deta hai: 2H₂O + 2F₂ → 4HF + O₂ — isliye F₂ ke saath aqueous halide displacement nahi karte!)*

## Part B: Disproportionation Reactions — Shart aur Fluorine ka Apvaad!

**Disproportionation hone ki Pakki Shart:**
> Jis tatva ka disproportionation hona hai, uska kam se kam **3 alag oxidation states** dikhana zaroori hai, aur shuruaat mein use **beech ke (intermediate) ON** mein hona chahiye — taaki ek hissa **upar (oxidise)** aur doosra hissa **neeche (reduce)** ja sake!

```
               ON BADHA (Oxidation: −1 --> 0)
                  +-------------------------> O₂  (ON = 0)
                  :
         2 H₂O₂  (O = −1, intermediate!)
                  :
                  +-------------------------> 2 H₂O (ON = −2)
               ON GHATA (Reduction: −1 --> −2)
```

> **Figure 2.1** – H₂O₂ ka decomposition ek classic disproportionation reaction hai: wahi Oxygen atom (−1) ek saath O₂ (0) mein oxidise aur H₂O (−2) mein reduce hota hai.

### 4 Mashhoor Disproportionation Reactions (Sabhi Yaad Rakho!)
1. **2H₂O₂(aq) → 2H₂O(l) + O₂(g)** *(O: −1 → −2 aur 0)*
2. **P₄(s) + 3OH⁻(aq) + 3H₂O(l) → PH₃(g) + 3H₂PO₂⁻(aq)** *(P: 0 → −3 aur +1; PH₃ zehreeli gas: sirf paper!)*
3. **S₈(s) + 12OH⁻(aq) → 4S²⁻(aq) + 2S₂O₃²⁻(aq) + 6H₂O(l)** *(S: 0 → −2 aur +2)*
4. **Cl₂(g) + 2OH⁻(aq, cold) → Cl⁻(aq) + ClO⁻(aq) + H₂O(l)** *(Cl: 0 → −1 aur +1 — bleaching agent banana!)*
   *(Hot concentrated alkali mein: **3Cl₂ + 6OH⁻ → 5Cl⁻ + ClO₃⁻ + 3H₂O**, Cl: 0 → −1 aur +5!)*

**Class 11 ka Sabse Famous Sawaal: Fluorine (F₂) alkali ke saath disproportionation kyun NAHI dikhata?**
- Kyunki **F poori periodic table mein sabse zyada electronegative (4.0)** hai — ye sirf **0 aur −1** dikha sakta hai, **kabhi positive ON (+1 ya +5) nahi dikha sakta!** Isliye F₂ disproportionation nahi kar sakta (2F₂ + 2OH⁻ → 2F⁻ + OF₂ + H₂O mein F sirf 0 → −1 reduce hota hai, oxidise nahi!).

## Solved Examples

### Example 1. Chaar Reactions ka Classification (Redox vs Non-Redox!)

**Sawaal:** In chaar reactions ko classify karo aur batao kaun-sa redox nahi hai:
(a) **2Mg(s) + O₂(g) → 2MgO(s)**
(b) **CaCO₃(s) → CaO(s) + CO₂(g)**
(c) **Fe(s) + CuSO₄(aq) → FeSO₄(aq) + Cu(s)**
(d) **2Cu⁺(aq) → Cu²⁺(aq) + Cu(s)**

**Hal:**
- (a) **Combination redox** (Mg: 0 → +2, O: 0 → −2).
- (b) **Non-redox decomposition!** (Ca +2, C +4, O −2 — kisi ka ON nahi badla!).
- (c) **Metal displacement redox** (Fe: 0 → +2, Cu: +2 → 0).
- (d) **Disproportionation redox** (Cu⁺: +1 → +2 aur +1 → 0!).

**Jaanch:** Har redox reaction mein ek ON badha aur ek ghata; (b) mein koi ON nahi badla ✅.

---

### Example 2. Halogen Displacement Predict Karna

**Sawaal:** Predict karo ki inmein se kaun-sa reaction hoga aur kaun-sa nahi:
(a) **Cl₂(g) + 2KBr(aq) → ?**   (b) **I₂(s) + 2KBr(aq) → ?**   *(Halogens toxic/corrosive: sirf paper!)*

**Hal:**
- Oxidising power: **F₂ > Cl₂ > Br₂ > I₂**.
- (a) Cl₂, Br₂ se zyada strong oxidiser hai → **HAAN, reaction hoga:** **Cl₂ + 2KBr → 2KCl + Br₂** (Cl: 0→−1, Br: −1→0).
- (b) I₂, Br₂ se kamzor oxidiser hai → **NAHI, koi reaction nahi hoga!**

**Jaanch:** Strong oxidiser weak halogen ko uske halide se bahar nikalta hai ✅.

## Aam galtiyan (bachke rehna)

1. **Galti 1: Har decomposition reaction ko redox maan lena!**
   **CaCO₃ → CaO + CO₂** aur **NH₄Cl → NH₃ + HCl** decomposition to hain, par **NON-REDOX** hain kyunki kisi atom ka ON nahi badalta!

2. **Galti 2: Fluorine (F₂) ka Cl₂ ki tarah alkali mein disproportionation likh dena.**
   F kabhi positive ON nahi dikha sakta — isliye **F₂ kabhi disproportionate nahi karta**!

3. **Galti 3: ClO₄⁻ (perchlorate) ka disproportionation dikha dena.**
   ClO₄⁻ mein Cl pehle se apne **maximum ON (+7)** par hai — ye aur upar oxidise nahi ho sakta! Sirf **ClO⁻ (+1), ClO₂⁻ (+3) aur ClO₃⁻ (+5)** disproportionate kar sakte hain!

---

## Quick Recap

- **4 Redox Types:** Combination (kam se kam 1 element), Decomposition (kam se kam 1 elemental product), Displacement (Metal & Non-metal; **F₂ > Cl₂ > Br₂ > I₂**), Disproportionation (wahi tatva ON ↑ aur ON ↓).
- **Non-redox traps:** CaCO₃ → CaO + CO₂, BaCl₂ + Na₂SO₄ → BaSO₄ + 2NaCl, HCl + NaOH → NaCl + H₂O.
- **Disproportionation rule:** Intermediate ON zaroori hai → **F₂** aur **ClO₄⁻** kabhi disproportionate nahi karte!
- **Comproportionation:** Disproportionation ka ulta (e.g., 2H₂S + SO₂ → 3S + 2H₂O).

## Practice Questions

1. Classify each of the following reactions as **combination redox, decomposition redox, displacement redox, disproportionation redox, or non-redox**:
   (a) **2H₂O(l) → 2H₂(g) + O₂(g)**
   (b) **BaCl₂(aq) + Na₂SO₄(aq) → BaSO₄(s) + 2NaCl(aq)**
   (c) **CH₄(g) + 2O₂(g) → CO₂(g) + 2H₂O(l)**
   (d) **3MnO₄²⁻ + 4H⁺ → 2MnO₄⁻ + MnO₂ + 2H₂O**
   (e) **Mg(s) + 2HCl(aq) → MgCl₂(aq) + H₂(g)**
   (f) **NH₄Cl(s) → NH₃(g) + HCl(g)**
2. Explain clearly why **Fluorine (F₂)** does NOT show a disproportionation reaction in alkaline medium, whereas **Cl₂, Br₂ and I₂** all do.
3. Among the oxoanions **ClO⁻, ClO₂⁻, ClO₃⁻ and ClO₄⁻**, which one CANNOT undergo disproportionation, and why?
4. Show using oxidation numbers that **2H₂S(g) + SO₂(g) → 3S(s) + 2H₂O(l)** is a **comproportionation** reaction (reverse of disproportionation). *(Toxic gases: paper problem only.)*
5. Predict whether each halogen displacement reaction will take place, and write the balanced equation if it does:
   (a) **Br₂(aq) + 2KI(aq) → ?**
   (b) **Cl₂(g) + 2NaF(aq) → ?**
   (c) **Cl₂(g) + 2KI(aq) → ?**
6. Explain with oxidation numbers why **2KClO₃(s) → 2KCl(s) + 3O₂(g)** is a decomposition redox reaction, whereas **CaCO₃(s) → CaO(s) + CO₂(g)** is NOT a redox reaction.
7. Write the balanced chemical equation for the disproportionation of **white phosphorus (P₄)** in hot aqueous NaOH, and show the change in oxidation number of Phosphorus. *(Pyrophoric/toxic: paper problem only.)*
8. Why does **H₂O₂** decompose slowly on standing (**2H₂O₂ → 2H₂O + O₂**)? Identify the oxidation number of Oxygen in the reactant and in both products.
9. Identify whether **2Na(s) + 2H₂O(l) → 2NaOH(aq) + H₂(g)** is a metal displacement or a non-metal (hydrogen) displacement reaction, and name the oxidising and reducing agents. *(Reactive metal: paper problem only.)*
10. Why do **double-displacement (precipitation and neutralisation)** reactions such as AgNO₃ + NaCl → AgCl + NaNO₃ never count as redox reactions?
11. Given **3Cl₂ + 6OH⁻ → 5Cl⁻ + ClO₃⁻ + 3H₂O**, verify that Chlorine undergoes both oxidation and reduction, and state the ratio of Cl atoms oxidised to Cl atoms reduced.
12. State whether each statement is True or False, and correct the false ones:
    (a) Every decomposition reaction is a redox reaction.
    (b) In disproportionation, the same element must exist in at least three different oxidation states.
    (c) Bromine can displace Chlorine from an aqueous NaCl solution.
    (d) Cu⁺(aq) disproportionates in water to give Cu²⁺(aq) and Cu(s).

### Answers

1. (a) **Decomposition redox** (H: +1→0, O: −2→0).
   (b) **Non-redox** (double displacement / precipitation — kisi ka ON nahi badla!).
   (c) **Redox (combustion)** (C: −4→+4, O: 0→−2).
   (d) **Disproportionation redox** (Mn: +6 → +7 aur +4!).
   (e) **Non-metal (H₂) displacement redox** (Mg: 0→+2, H: +1→0).
   (f) **Non-redox decomposition** (N −3, H +1, Cl −1 sab wahi!).

2. Disproportionation ke liye tatva ka ON ek taraf badhna (positive) aur doosri taraf ghatna (negative) zaroori hai. Fluorine sabse zyada electronegative (4.0) hai aur kabhi positive ON nahi dikha sakta — isliye F₂ disproportionation nahi kar sakta!

3. **ClO₄⁻** disproportionate nahi kar sakta kyunki ismein Cl pehle se apne **maximum ON (+7)** par hai (aur upar oxidise nahi ho sakta!). Baaki teeno (+1, +3, +5) intermediate states mein hain, isliye disproportionate kar sakte hain.

4. H₂S mein S = **−2** (oxidised to 0), aur SO₂ mein S = **+4** (reduced to 0). Do alag ON (−2 aur +4) milkar beech ka ek common ON **0 (S)** bana rahe hain → **Comproportionation**!
   Jaanch: 2(−2 → 0) = +4 loss; 1(+4 → 0) = −4 gain (balanced!) ✅.

5. (a) **Haan!** Br₂ > I₂ → **Br₂ + 2KI → 2KBr + I₂**.
   (b) **Nahi!** Cl₂, F₂ se kamzor oxidiser hai → **No reaction**.
   (c) **Haan!** Cl₂ > I₂ → **Cl₂ + 2KI → 2KCl + I₂**.

6. **2KClO₃ → 2KCl + 3O₂** mein Cl (+5 → −1) reduce aur O (−2 → 0) oxidise hota hai → redox! **CaCO₃ → CaO + CO₂** mein Ca (+2), C (+4) aur O (−2) bilkul nahi badalte → non-redox!

7. **P₄ + 3OH⁻ + 3H₂O → PH₃ + 3H₂PO₂⁻**.
   Phosphorus: **0 → −3** (PH₃ mein reduced) aur **0 → +1** (H₂PO₂⁻ mein oxidised)!
   Jaanch: 1(−3) + 3(+1) = 0 net e⁻ change ✅.

8. H₂O₂ mein Oxygen intermediate state (**−1**) mein hota hai, jo unstable hai: ek hissa **H₂O (−2)** mein reduce aur doosra **O₂ (0)** mein oxidise hokar disproportionation karta hai!

9. Ye **Non-metal (Hydrogen) displacement** redox reaction hai. **Na** (0 → +1) = reducing agent; **H₂O** (H: +1 → 0) = oxidising agent.

10. Double-displacement reactions mein sirf ions aapas mein partner badalte hain (Ag⁺, NO₃⁻, Na⁺, Cl⁻) — kisi bhi ion ka **oxidation number nahi badalta**, isliye we redox nahi hote!

11. Cl₂ (0) → 5 Cl⁻ (**−1**, reduced) + 1 ClO₃⁻ (**+5**, oxidised).
    Ratio of Cl atoms oxidised : reduced = **1 : 5**!
    Jaanch: 1 × (+5) = +5 loss; 5 × (−1) = −5 gain ✅.

12. (a) **False** ❌. CaCO₃ → CaO + CO₂ aur NH₄Cl → NH₃ + HCl non-redox decompositions hain.
    (b) **True** ✅.
    (c) **False** ❌. Cl₂ > Br₂, isliye Br₂, Cl⁻ ko displace **nahi** kar sakta.
    (d) **True** ✅. 2Cu⁺ (+1) → Cu²⁺ (+2) + Cu (0).
