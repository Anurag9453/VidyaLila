## Part B: 6 Mixed Worked Problems

### Example 1: Do Circles ke Equal Arcs ka Radius Ratio

Agar do circles mein **barabar lambai (l)** ki arcs unke centres par **60°** aur **75°** ke angles banati hain, to unke radii r₁ aur r₂ ka ratio **r₁ : r₂** nikalo.

**Hal:**
1. Dono angles ko radians mein badlo:
   θ₁ = 60° = π/3 rad,  θ₂ = 75° = 75π/180 = 5π/12 rad.
2. Kyunki arc length l dono mein barabar hai:
   **r₁ θ₁ = r₂ θ₂**
   r₁ / r₂ = θ₂ / θ₁ = (5π/12) ÷ (π/3) = (5/12) × 3 = **5 / 4**.
Isliye **r₁ : r₂ = 5 : 4**.

**Jaanch:** r₁ = 5, θ₁ = 60° → l₁ = 5 × π/3 = 5π/3; r₂ = 4, θ₂ = 75° → l₂ = 4 × 5π/12 = 5π/3 ✅!

---

### Example 2: Half-Angle in Quadrant III — cos x = −1/3

Agar **cos x = −1/3** aur **x Quadrant III** mein hai (π < x < 3π/2), to **sin(x/2)**, **cos(x/2)** aur **tan(x/2)** nikalo.

**Hal:**
1. **x/2 ka quadrant:** π < x < 3π/2 ko 2 se bhaag do: **π/2 < x/2 < 3π/4** → **Quadrant II**!
   Q II mein **sin(x/2) positive (+)** aur **cos(x/2), tan(x/2) negative (−)** honge!
2. **sin(x/2)** = +√[(1 − (−1/3)) / 2] = √[(4/3) / 2] = √(2/3) = **√6 / 3**.
3. **cos(x/2)** = −√[(1 + (−1/3)) / 2] = −√[(2/3) / 2] = −√(1/3) = **−√3 / 3**.
4. **tan(x/2)** = sin(x/2) / cos(x/2) = (√6 / 3) ÷ (−√3 / 3) = **−√2**.

**Jaanch:** (√6/3)² + (−√3/3)² = 6/9 + 3/9 = 1 ✅; 2 cos²(x/2) − 1 = 2(1/3) − 1 = −1/3 = cos x ✅!

---

### Example 3: Classic Tangent Identity — tan 3x tan 2x tan x = tan 3x − tan 2x − tan x

Prove karo: **tan 3x tan 2x tan x = tan 3x − tan 2x − tan x**.

**Hal:**
1. 3x = 2x + x ke dono taraf tan lo:
   tan 3x = tan(2x + x) = (tan 2x + tan x) / (1 − tan 2x tan x)
2. Cross-multiply karo:
   tan 3x (1 − tan 2x tan x) = tan 2x + tan x
   tan 3x − tan 3x tan 2x tan x = tan 2x + tan x
3. Rearrange karo:
   **tan 3x tan 2x tan x = tan 3x − tan 2x − tan x**. (Proved!)

**Jaanch:** x = 15° (tan 15° = 2 − √3, tan 30° = 1/√3, tan 45° = 1) par LHS = 2/√3 − 1 aur RHS = 1 − 1/√3 − (2 − √3) = 2/√3 − 1 ✅!

---

### Example 4: Symmetric Pairing + C–D Identity

Prove karo: **(sin 5x − 2 sin 3x + sin x) ÷ (cos 5x − cos x) = tan x**.

**Hal:**
- **Numerator** mein sabse bade (5x) aur sabse chhote (x) ko saath rakho:
  (sin 5x + sin x) − 2 sin 3x
  = 2 sin 3x cos 2x − 2 sin 3x   *(C–D formula: (5x + x)/2 = 3x, (5x − x)/2 = 2x)*
  = 2 sin 3x (cos 2x − 1)
  = 2 sin 3x (−2 sin² x) = **−4 sin 3x sin² x**.   *(kyunki 1 − cos 2x = 2 sin² x)*
- **Denominator:**
  cos 5x − cos x = −2 sin 3x sin 2x = −2 sin 3x (2 sin x cos x) = **−4 sin 3x sin x cos x**.
- **Ratio:**
  (−4 sin 3x sin² x) ÷ (−4 sin 3x sin x cos x) = sin x / cos x = **tan x** = RHS!

**Jaanch:** x = 15° par numerator = sin 75° − 2 sin 45° + sin 15° = (√6+√2)/4 − √2 + (√6−√2)/4 = (2√6 − 4√2)/4 = (√6 − 2√2)/2; denominator = cos 75° − cos 15° = −√2/2; ratio = (2√2 − √6)/√2 = 2 − √3 = tan 15° ✅!

---

### Example 5: 3-Term Trig Equation — sin x + sin 3x + sin 5x = 0

**sin x + sin 3x + sin 5x = 0** ka general solution nikalo.

**Hal:**
1. Symmetric pairing: (sin 5x + sin x) + sin 3x = 0.
2. C–D lagao: 2 sin 3x cos 2x + sin 3x = 0.
3. Factor karo: **sin 3x (2 cos 2x + 1) = 0**.
4. Do branches:
   - sin 3x = 0 ⟹ 3x = nπ ⟹ **x = nπ / 3**
   - cos 2x = −1/2 = cos(2π/3) ⟹ 2x = 2nπ ± 2π/3 ⟹ **x = nπ ± π/3** (n ∈ Z).
   *(Dhyan do: nπ ± π/3 ke sabhi angles pehle se hi x = nπ/3 ke andar aa jaate hain! Isliye poora solution sirf **x = nπ/3, n ∈ Z** hai!)*

**Jaanch:** x = π/3 par sin(π/3) + sin π + sin(5π/3) = √3/2 + 0 − √3/2 = 0 ✅!

---

### Example 6: Auxiliary Angle Method — √3 cos x + sin x = √2

**√3 cos x + sin x = √2** ka general solution nikalo.

**Hal:**
Ye **a cos x + b sin x = c** roop ki equation hai, jahan a = √3, b = 1.
1. **√(a² + b²)** nikalo: √((√3)² + 1²) = √(3 + 1) = **2**.
2. Poori equation ko **2** se bhaag do:
   **(√3 / 2) cos x + (1 / 2) sin x = √2 / 2 = 1 / √2**
3. √3/2 = cos(π/6) aur 1/2 = sin(π/6) rakho:
   cos x cos(π/6) + sin x sin(π/6) = 1 / √2
   **cos(x − π/6) = cos(π/4)**   *(cos(A − B) formula!)*
4. Theorem 2 lagao:
   x − π/6 = 2nπ ± π/4
   - (+) sign: x = 2nπ + π/4 + π/6 = **2nπ + 5π/12**
   - (−) sign: x = 2nπ − π/4 + π/6 = **2nπ − π/12** (n ∈ Z).

*(Bonus insight: Isi tareeke se **a cos x + b sin x** ka maximum maan **+√(a² + b²)** aur minimum maan **−√(a² + b²)** hota hai! Isliye a cos x + b sin x = c ka hal tabhi hota hai jab |c| ≤ √(a² + b²)!)*

**Jaanch:** x = 5π/12 (75°) par √3 cos 75° + sin 75° = √3(√6 − √2)/4 + (√6 + √2)/4 = (3√2 − √6 + √6 + √2)/4 = 4√2/4 = √2 ✅!

## Aam galtiyan (Chapter Synthesis)

1. **|sin x| > 1 ya |c| > √(a² + b²) wale equations ka zabardasti solution likh dena:**
   - *Sahi soch:* Pehle range check karo! Jaise 3 cos x + 4 sin x = 6 ka koi real hal nahi kyunki max value sirf √(3² + 4²) = 5 < 6 hai!
2. **tan(A + B) wahan laga dena jahan A + B = π/2 (90°) ho:**
   - *Galat kyun:* tan 90° undefined hai (denominator 1 − tan A tan B = 0 ho jaata hai)! Aise cases mein sin aur cos mein badal kar hal karo.
3. **a cos x + b sin x = c mein dono taraf cos x se bhaag de dena (√(a² + b²) ke bajay):**
   - *Galat kyun:* cos x se bhaag dene par a + b tan x = c sec x ban jaata hai, jo aur ulajh jaata hai! Hamesha **√(a² + b²)** se bhaag dekar single cos(x − α) ya sin(x + α) banao.

## Quick Recap

- **Degrees ↔ Radians:** π rad = 180°, **l = rθ** (θ in radians).
- **Unit circle & ASTC:** Quadrant sign + allied angles + periodic graphs.
- **Compound, Multiple, C–D:** Saare formulas cos(x + y) se jude hain; 3–4 terms mein symmetric pairing karo.
- **Equations:** Factor (never cancel), principal in [0, 2π), general with n ∈ Z; **a cos x + b sin x = c** ko √(a² + b²) se bhaag do.

## Practice Questions

1. Two circles have arcs of the same length subtending angles of 45° and 60° at their centres. Find the ratio of their radii r₁ : r₂.

2. If **sin x = 1/4** and x lies in Quadrant II (π/2 < x < π), find **sin(x/2)**, **cos(x/2)**, and **tan(x/2)**.

3. Prove that: **2 cos(π/13) cos(9π/13) + cos(3π/13) + cos(5π/13) = 0**.

4. Prove that: **(sin 3x + sin x) sin x + (cos 3x − cos x) cos x = 0**.

5. Prove that: **(cos x − cos y)² + (sin x − sin y)² = 4 sin²((x − y)/2)**.

6. Prove that: **sin x + sin 3x + sin 5x + sin 7x = 4 cos x cos 2x sin 4x**.

7. Prove that: **[(sin 7x + sin 5x) + (sin 9x + sin 3x)] ÷ [(cos 7x + cos 5x) + (cos 9x + cos 3x)] = tan 6x**.

8. Find the general solution of **cos x + √3 sin x = 1**.

9. Find the general solution of **sin x + cos x = √2**.

10. Find the maximum and minimum values of **f(x) = 3 cos x + 4 sin x + 7**.

11. Prove that: **cos² x + cos²(x + π/3) + cos²(x − π/3) = 3/2**.

12. Find all values of x in [0, 2π) satisfying **2 cos² x − 3 cos x + 1 = 0**.

### Answers

1. θ₁ = 45° = π/4, θ₂ = 60° = π/3. r₁θ₁ = r₂θ₂ ⟹ r₁/r₂ = (π/3) ÷ (π/4) = **4 : 3**. Jaanch: 4(π/4) = π = 3(π/3) ✅.

2. Q II mein cos x = −√(1 − 1/16) = −√15/4.
   π/2 < x < π ⟹ π/4 < x/2 < π/2 (Q I: teeno +!).
   - sin(x/2) = √[(1 + √15/4)/2] = **√(8 + 2√15) / 4** = **(√5 + √3) / 4** (kyunki (√5 + √3)² = 8 + 2√15!).
   - cos(x/2) = √[(1 − √15/4)/2] = **√(8 − 2√15) / 4** = **(√5 − √3) / 4**.
   - tan(x/2) = (√5 + √3)/(√5 − √3) = (8 + 2√15)/2 = **4 + √15**.
   Jaanch: [(√5 + √3)² + (√5 − √3)²]/16 = 16/16 = 1 ✅!

3. Pehle term mein Product-to-Sum lagao: 2 cos(9π/13) cos(π/13) = cos(10π/13) + cos(8π/13).
   Par 10π/13 = π − 3π/13 ⟹ cos(10π/13) = −cos(3π/13)!
   Aur 8π/13 = π − 5π/13 ⟹ cos(8π/13) = −cos(5π/13)!
   LHS = −cos(3π/13) − cos(5π/13) + cos(3π/13) + cos(5π/13) = **0**.

4. LHS = sin 3x sin x + sin² x + cos 3x cos x − cos² x
   = (cos 3x cos x + sin 3x sin x) − (cos² x − sin² x)
   = cos(3x − x) − cos 2x = cos 2x − cos 2x = **0**.

5. Expand karo: (cos² x + sin² x) + (cos² y + sin² y) − 2(cos x cos y + sin x sin y)
   = 2 − 2 cos(x − y) = 2(1 − cos(x − y)) = **4 sin²((x − y)/2)** = RHS.

6. Pairing (7x, x) aur (5x, 3x):
   LHS = (sin 7x + sin x) + (sin 5x + sin 3x)
   = 2 sin 4x cos 3x + 2 sin 4x cos x
   = 2 sin 4x (cos 3x + cos x)
   = 2 sin 4x (2 cos 2x cos x) = **4 cos x cos 2x sin 4x** = RHS.

7. Numerator = 2 sin 6x cos x + 2 sin 6x cos 3x = 2 sin 6x (cos x + cos 3x).
   Denominator = 2 cos 6x cos x + 2 cos 6x cos 3x = 2 cos 6x (cos x + cos 3x).
   Ratio = 2 sin 6x / 2 cos 6x = **tan 6x** = RHS.

8. √(1² + (√3)²) = 2 se bhaag do: (1/2) cos x + (√3/2) sin x = 1/2 ⟹ cos(x − π/3) = cos(π/3).
   x − π/3 = 2nπ ± π/3 ⟹ **x = 2nπ + 2π/3** ya **x = 2nπ** (n ∈ Z).
   Jaanch: x = 0 par 1 + 0 = 1 ✅; x = 2π/3 par −1/2 + √3(√3/2) = −1/2 + 3/2 = 1 ✅.

9. √(1² + 1²) = √2 se bhaag do: (1/√2) cos x + (1/√2) sin x = 1 ⟹ cos(x − π/4) = 1 = cos 0.
   x − π/4 = 2nπ ⟹ **x = 2nπ + π/4, n ∈ Z**. Jaanch: sin(π/4) + cos(π/4) = 2/√2 = √2 ✅.

10. 3 cos x + 4 sin x ka range [−√(3² + 4²), +√(3² + 4²)] = [−5, 5].
    7 jodo: −5 + 7 ≤ f(x) ≤ 5 + 7 ⟹ **Minimum = 2**, **Maximum = 12**. Jaanch: 7 − 5 = 2, 7 + 5 = 12 ✅.

11. cos² θ = (1 + cos 2θ)/2 lagao:
    LHS = (1/2) [3 + cos 2x + cos(2x + 2π/3) + cos(2x − 2π/3)]
    = (1/2) [3 + cos 2x + 2 cos 2x cos(2π/3)]
    = (1/2) [3 + cos 2x + 2 cos 2x (−1/2)] = (1/2) [3 + cos 2x − cos 2x] = **3/2**.
    Jaanch: x = 0 par 1 + 1/4 + 1/4 = 3/2 ✅.

12. (2 cos x − 1)(cos x − 1) = 0 ⟹ cos x = 1/2 ya cos x = 1.
    [0, 2π) mein solutions: **0, π/3, 5π/3**. Jaanch: cos 0 = 1 → 2 − 3 + 1 = 0; cos(π/3) = 1/2 → 1/2 − 3/2 + 1 = 0 ✅.
