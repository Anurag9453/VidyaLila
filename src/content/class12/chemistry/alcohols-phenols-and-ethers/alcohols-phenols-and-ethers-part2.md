## Naye Shabd (Key Terms)

| Term | Hinglish Meaning |
|---|---|
| **Hydroboration–Oxidation** | Alkene + B₂H₆ (THF), phir H₂O₂ / OH⁻ → **anti-Markovnikov** hydration (1° alcohol banta hai bina carbocation rearrangement ke!) |
| **Cumene (Isopropylbenzene)** | C₆H₅–CH(CH₃)₂ — air oxidation aur acid hydrolysis se **phenol + acetone** deta hai |
| **Williamson Ether Synthesis** | Sodium alkoxide (R–O⁻Na⁺) + primary alkyl halide (R'–X) → R–O–R' + NaX (SN2 mechanism!) |

## 1. Preparation of Alcohols

### (a) From Alkenes (2 Complementary Methods!)
1. **Acid-Catalysed Hydration (Markovnikov Addition):**
   CH₃–CH=CH₂ + H₂O —(H⁺)→ **CH₃–CH(OH)–CH₃ (Propan-2-ol)**
   - **3-Step Mechanism (Exam Favourite!):**
     - Step 1: Protonation of alkene to form more stable **carbocation** (H⁺ + H₂O ⇌ H₃O⁺; CH₃–CH=CH₂ + H₃O⁺ → CH₃–CH⁺–CH₃ + H₂O).
     - Step 2: Nucleophilic attack of H₂O on carbocation → protonated alcohol.
     - Step 3: Deprotonation (loss of H⁺) → alcohol + H₃O⁺ regenerated.
2. **Hydroboration–Oxidation (Anti-Markovnikov Addition):**
   3CH₃–CH=CH₂ + ½(BH₃)₂ → (CH₃–CH₂–CH₂)₃B —(H₂O₂ / aq. NaOH)→ **3CH₃–CH₂–CH₂–OH (Propan-1-ol)** + B(OH)₃
   - Result: –OH goes to the **less substituted (terminal)** carbon!

### (b) By Reduction of Carbonyl Compounds & Carboxylic Acids
- **Aldehyde → 1° alcohol:** R–CHO + H₂ (Pd/Ni) ya NaBH₄ ya LiAlH₄ → **R–CH₂OH**.
- **Ketone → 2° alcohol:** R–CO–R' + NaBH₄ ya LiAlH₄ → **R–CH(OH)–R'**.
- **Carboxylic acid / Ester → 1° alcohol:** Needs strong reducing agent **LiAlH₄** (NaBH₄ acids/esters ko reduce nahi karta!). Industrially, R–COOH → ester → catalytic hydrogenation (H₂ / catalyst) → R–CH₂OH (cheaper than LiAlH₄!).

### (c) From Grignard Reagents (R–Mg–X + Carbonyl → Alcohol!) — SUPER IMPORTANT!
Step 1: Nucleophilic addition in dry ether; Step 2: Acidic hydrolysis (H₂O / H⁺):
1. **Methanal (HCHO) + R–Mg–X → 1° Alcohol** (R–CH₂OH)
2. **Any other Aldehyde (R'–CHO) + R–Mg–X → 2° Alcohol** (R'–CH(OH)–R)
3. **Any Ketone (R'–CO–R'') + R–Mg–X → 3° Alcohol** (R'R''C(OH)–R)

## 2. Preparation of Phenols (4 Methods!)

1. **From Haloarenes (Dow's Process):**
   C₆H₅–Cl + NaOH —(623 K, 300 atm)→ C₆H₅–ONa —(HCl)→ **C₆H₅–OH**.
2. **From Benzenesulphonic Acid:**
   Benzene + Oleum (H₂S₂O₇) → C₆H₅–SO₃H —(1. molten NaOH, 2. H⁺)→ **C₆H₅–OH**.
3. **From Diazonium Salts (Lab Method):**
   Aniline —(NaNO₂ + HCl, 0–5°C)→ C₆H₅–N₂⁺Cl⁻ —(warm H₂O)→ **C₆H₅–OH** + N₂↑ + HCl.
4. **From Cumene (Commercial / Industrial Method — MOST IMPORTANT!):**
   - Step 1 (Air oxidation): C₆H₅–CH(CH₃)₂ (Cumene) + O₂ → **C₆H₅–C(CH₃)₂–O–O–H** (Cumene hydroperoxide)
   - Step 2 (Dilute acid H⁺ / H₂O): Cumene hydroperoxide → **C₆H₅–OH (Phenol)** + **CH₃–CO–CH₃ (Acetone)**!

## 3. Preparation of Ethers (2 Methods!)

### (a) Acid-Catalysed Dehydration of Alcohols (Only for Symmetrical 1° Ethers!)
**2CH₃–CH₂–OH —(conc. H₂SO₄, 413 K)→ CH₃–CH₂–O–CH₂–CH₃ (Ethoxyethane) + H₂O**
- **Temperature trap!** **413 K (140°C)** → **Ether** (SN2); **443 K (170°C)** → **Alkene (Ethene)** (elimination)!
- **Limitation:** Sirf **1° alcohols** ke liye kaam karta hai! 2° aur 3° alcohols mein elimination jeet jata hai aur **alkene** banta hai!

### (b) Williamson Ether Synthesis (Best for Both Symmetrical & Unsymmetrical Ethers!)
**R–O⁻Na⁺ + R'–X → R–O–R' + NaX**   (Proceeds by **SN2 mechanism**!)

**GOLDEN RULE OF WILLIAMSON SYNTHESIS (100% Exam Question!):**
Because it is an **SN2** reaction, the **alkyl halide (R'–X) MUST BE PRIMARY (1°)** (least steric hindrance)!
- Agar tumhe **tert-butyl methyl ether** ((CH₃)₃C–O–CH₃) banana hai:
  - **CORRECT route:** **(CH₃)₃C–O⁻Na⁺ (3° alkoxide) + CH₃–Br (1° halide)** → **(CH₃)₃C–O–CH₃** + NaBr!
  - **WRONG route:** CH₃–O⁻Na⁺ + (CH₃)₃C–Br (3° halide) → Elimination wins → **2-Methylpropene (alkene!)** + CH₃OH + NaBr!
- **Phenolic ethers (Anisole):** C₆H₅–O⁻Na⁺ (sodium phenoxide) + CH₃–Br → **C₆H₅–O–CH₃ (Anisole)** + NaBr! (Never use C₆H₅–Br + CH₃ONa because aryl halides don't undergo SN2!)

## Solved Examples

### Example 1: Choosing the Right Williamson Synthesis Route
Write the best pair of reactants to prepare **tert-butyl ethyl ether** ((CH₃)₃C–O–C₂H₅) by Williamson synthesis. What happens if you reverse the reactants?

**Solution:**
- **Correct pair (3° alkoxide + 1° halide):**
  **(CH₃)₃C–O⁻Na⁺ + CH₃–CH₂–Br → (CH₃)₃C–O–CH₂–CH₃** + NaBr (clean SN2!).
- **Reversed pair (1° alkoxide + 3° halide):**
  CH₃–CH₂–O⁻Na⁺ + (CH₃)₃C–Br → **CH₂=C(CH₃)₂ (2-methylpropene)** + C₂H₅OH + NaBr (elimination dominates over SN2 because 3° halide is sterically hindered!).

Jaanch: Always put the bulky/tertiary group on the alkoxide (O⁻) and the primary group on the halide (–X) ✅

---

### Example 2: Preparing Alcohols via Grignard Reagent
Show how you would synthesise **butan-2-ol** from **ethanal (CH₃CHO)** using a Grignard reagent.

**Solution:**
Butan-2-ol is CH₃–CH(OH)–CH₂CH₃ (a 2° alcohol). We already have CH₃–CH=O, so we need to attach an ethyl group (–CH₂CH₃) via **ethylmagnesium bromide (CH₃CH₂MgBr)**:
CH₃–CHO + CH₃CH₂MgBr —(dry ether)→ CH₃–CH(OMgBr)–CH₂CH₃ —(H₂O / H⁺)→ **CH₃–CH(OH)–CH₂CH₃ (Butan-2-ol)** + Mg(OH)Br.

Jaanch: 2 C (ethanal) + 2 C (ethyl Grignard) = 4 C (butan-2-ol, 2° alcohol) ✅

---

### Example 3: Propene to Propan-1-ol vs Propan-2-ol
How will you convert propene (CH₃–CH=CH₂) into: (a) propan-2-ol, (b) propan-1-ol?

**Solution:**
(a) **Acid-catalysed hydration (Markovnikov):** CH₃–CH=CH₂ + H₂O —(H⁺)→ **CH₃–CH(OH)–CH₃ (propan-2-ol)**.
(b) **Hydroboration–oxidation (anti-Markovnikov):** CH₃–CH=CH₂ —(1. B₂H₆/THF, 2. H₂O₂/OH⁻)→ **CH₃–CH₂–CH₂–OH (propan-1-ol)**.

Jaanch: Both are single-pot conversions with opposite regioselectivity ✅

## Aam Galtiyan (Common Mistakes)

1. **Williamson synthesis mein 3° alkyl halide choose kar lena:**
   - *Galat:* CH₃ONa + (CH₃)₃CBr → tert-butyl methyl ether.
   - *Sahi:* 3° halide ke saath alkoxide strong base ki tarah behave karke **alkene (2-methylpropene)** bana deta hai! Hamesha **(CH₃)₃CONa + CH₃Br** lo!

2. **Ethanol + conc. H₂SO₄ mein 413 K aur 443 K mix kar dena:**
   - *Galat:* 443 K par diethyl ether banta hai.
   - *Sahi:* **413 K (lower temp) → Ether** (C₂H₅–O–C₂H₅); **443 K (higher temp) → Alkene** (CH₂=CH₂)!

3. **Anisole banane ke liye chlorobenzene + CH₃ONa likh dena:**
   - *Galat:* C₆H₅Cl + CH₃ONa → C₆H₅OCH₃.
   - *Sahi:* Aryl halide SN2 nahi deta! **Sodium phenoxide (C₆H₅ONa) + CH₃Br** use karo!

## Quick Recap

- **Alkenes → Alcohols:** H₂O/H⁺ = Markovnikov; B₂H₆ then H₂O₂/OH⁻ = anti-Markovnikov.
- **Grignard + Carbonyl:** HCHO → 1°; RCHO → 2°; RCOR' → 3° alcohol.
- **Phenol (commercial):** **Cumene** + O₂ → cumene hydroperoxide —(H⁺/H₂O)→ **Phenol + Acetone**.
- **Ethers:** 2ROH + conc. H₂SO₄ (413 K, 1° only); **Williamson** (R–O⁻Na⁺ + **1° R'–X** → R–O–R').

### Answers

1. Step 1: H₂C=CH₂ + H₃O⁺ → CH₃–CH₂⁺ + H₂O (protonation → carbocation).
   Step 2: CH₃–CH₂⁺ + H₂O → CH₃–CH₂–O⁺H₂ (nucleophilic attack by water).
   Step 3: CH₃–CH₂–O⁺H₂ + H₂O → **CH₃–CH₂–OH** + H₃O⁺ (deprotonation).
2. Addition of diborane (B₂H₆) to an alkene followed by alkaline H₂O₂ oxidation to yield the anti-Markovnikov alcohol:
   CH₃CH₂CH=CH₂ —(1. B₂H₆/THF, 2. H₂O₂/OH⁻)→ **CH₃CH₂CH₂CH₂OH (butan-1-ol)**.
3. (a) HCHO + CH₃MgBr → **CH₃CH₂OH (ethanol, 1°)**.
   (b) CH₃CH₂CHO + CH₃MgBr → **CH₃CH₂CH(OH)CH₃ (butan-2-ol, 2°)**.
   (c) CH₃COCH₃ + CH₃MgBr → **(CH₃)₃COH (2-methylpropan-2-ol, 3°)**.
   Jaanch: Carbon count increases by +1 in every case: 1+1=2, 3+1=4, 3+1=4 ✅
4. C₆H₅–CH(CH₃)₂ + O₂ → C₆H₅–C(CH₃)₂–OOH (cumene hydroperoxide) —(H⁺/H₂O)→ **C₆H₅–OH (phenol)** + **CH₃COCH₃ (acetone)**. Valuable by-product: **Acetone**.
5. C₆H₅–NH₂ + NaNO₂ + HCl —(273–278 K)→ C₆H₅–N₂⁺Cl⁻ —(warm H₂O)→ **C₆H₅–OH** + N₂↑ + HCl.
6. Because 3° alcohols (like tert-butanol) readily form a stable 3° carbocation and undergo **elimination** to give an **alkene (2-methylpropene)** rather than SN2 ether formation.
7. (a) **C₆H₅–O⁻Na⁺ + CH₃–Br → C₆H₅–O–CH₃ (anisole)** + NaBr.
   (b) **(CH₃)₃C–O⁻Na⁺ + CH₃–Br → (CH₃)₃C–O–CH₃** + NaBr.
8. Elimination dominates over SN2 because the halide is tertiary:
   CH₃–O⁻Na⁺ + (CH₃)₃C–Br → **CH₂=C(CH₃)₂ (2-methylpropene)** + CH₃OH + NaBr.
9. NaBH₄ is a mild selective reducing agent (reduces only aldehydes and ketones), whereas LiAlH₄ is a very strong hydride donor capable of reducing less reactive carboxylic acids and esters.
10. (a) C₆H₅–Cl + NaOH —(623 K, 300 atm)→ C₆H₅–ONa —(H⁺)→ **C₆H₅–OH**.
    (b) 2CH₃CH₂OH —(conc. H₂SO₄, 413 K)→ **CH₃CH₂–O–CH₂CH₃** + H₂O.
