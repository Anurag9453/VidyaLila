# Topic 2: Squares wali Identities se Value Nikalna

Topic 1 mein humne brackets ko kholna seekha tha. (a + b)², (a − b)², (a + b)(a − b) aur (x + a)(x + b) ko area wali picture se samjha, bahut saare expansions kiye, aur 102² ya 103 × 97 jaise sawaal mann mein hal kiye.

Ab hum in identities ka ek naya kaam dekhenge. Kabhi kabhi humein **a aur b khud pata nahi hote**, sirf unke baare mein kuch baatein pata hoti hain, jaise unka jod aur guna. Phir bhi identities ki madad se hum a² + b², (a − b)² jaisi cheezein nikaal sakte hain, **bina a aur b dhundhe**. Yahi is topic ka jaadu hai.

## Nani ki paheli

Garmi ki chhuttiyan thin. Mishti apni nani ke ghar gayi thi. Shaam ko nani ne chai ke saath ek paheli poochi:

"Maine do numbers soche hain. Unka **jod 10** hai, aur unka **guna 21** hai. Ab bata, un dono ke **squares ka jod** kitna hai? Par shart ye hai ki tu pehle numbers dhundhne nahi baithegi."

Mishti ne socha, "Numbers dhundhe bina squares ka jod kaise?"

Nani muskurayi aur boli, "Tune (a + b)² padha hai na? Bas usi ko ulta padh."

Mishti ne likha:

(a + b)² = a² + 2ab + b²

Jod pata hai: a + b = 10, to (a + b)² = 100.
Guna pata hai: ab = 21, to 2ab = 42.

To a² + b² = 100 − 42 = **58**.

Nani ne taali bajayi. "Ab check kar. Mere numbers 3 aur 7 the." Mishti ne jaancha: 3² + 7² = 9 + 49 = 58. Bilkul sahi!

Is topic mein hum yahi kala seekhenge: **jo pata hai, usse jo poocha hai, wo identity ke raaste nikaalna.**

## Part A: Purani identities se nayi baatein

Topic 1 ki do identities yaad karo:

- (a + b)² = a² + 2ab + b²
- (a − b)² = a² − 2ab + b²

Inhe dobara prove nahi karenge. Bas inhe **ulat-palat** karke char nayi kaam ki baatein nikaalenge.

### Result 1: a² + b² ke do roop

Pehli identity mein 2ab ko doosri taraf le jao:

**a² + b² = (a + b)² − 2ab**

Doosri identity mein −2ab ko doosri taraf le jao:

**a² + b² = (a − b)² + 2ab**

Matlab a² + b² nikaalne ke liye do raaste hain. Jod pata ho to pehla, fark pata ho to doosra.

### Result 2: Dono squares ka fark

Pehli identity mein se doosri ghatao:

(a + b)² − (a − b)²
= (a² + 2ab + b²) − (a² − 2ab + b²)
= a² + 2ab + b² − a² + 2ab − b²
= **4ab**

**(a + b)² − (a − b)² = 4ab**

Jaanch: a = 5, b = 2. (7)² − (3)² = 49 − 9 = 40, aur 4 × 5 × 2 = 40 ✅

### Result 3: Dono squares ka jod

Dono identities ko jodo:

(a + b)² + (a − b)²
= (a² + 2ab + b²) + (a² − 2ab + b²)
= **2a² + 2b²**

**(a + b)² + (a − b)² = 2(a² + b²)**

Jaanch: a = 5, b = 2. 49 + 9 = 58, aur 2(25 + 4) = 58 ✅

### Result 4: Jod se fark tak ka pul

Result 2 ko rearrange karo:

**(a − b)² = (a + b)² − 4ab**

Isi tarah: **(a + b)² = (a − b)² + 4ab**

Ye do formulae bahut kaam ke hain. Jod aur guna pata ho to fark nikal aata hai, aur fark aur guna pata ho to jod.

### Ek nazar mein

| Pata hai | Nikaalna hai | Formula |
|---|---|---|
| a + b aur ab | a² + b² | (a + b)² − 2ab |
| a − b aur ab | a² + b² | (a − b)² + 2ab |
| a + b aur ab | (a − b)² | (a + b)² − 4ab |
| a − b aur ab | (a + b)² | (a − b)² + 4ab |
| a² + b² aur ab | (a + b)² | a² + b² + 2ab |
| a² + b² aur ab | (a − b)² | a² + b² − 2ab |

Isse ratne ki zaroorat nahi hai. Bas do Topic 1 wali identities yaad raho, baaki sab unhi se nikal aata hai.

## Part B: Value nikaalne wale sawaal

### Example 1: a + b = 7 aur ab = 12. a² + b², (a − b)² aur a − b nikaalo.

**a² + b²:**
a² + b² = (a + b)² − 2ab = 49 − 24 = **25**

**(a − b)²:**
(a − b)² = (a + b)² − 4ab = 49 − 48 = **1**

**a − b:**
(a − b)² = 1, to a − b = **±1**

Jaanch: Numbers 3 aur 4 hain (3 + 4 = 7, 3 × 4 = 12). 3² + 4² = 9 + 16 = 25 ✅. Agar a = 4, b = 3 to a − b = 1. Agar a = 3, b = 4 to a − b = −1. Dono sahi hain, isliye ±1 ✅

### ± kyun aata hai?

Ye bahut zaroori baat hai, dhyan se samjho.

- 3² = 9
- (−3)² = 9 bhi!

Matlab agar kisi ka square 9 hai, to wo number **3 bhi ho sakta hai aur −3 bhi**. Isliye jab hum square root lete hain aur humein pakka nahi pata ki number positive hai ya negative, to **± lagate hain**.

Upar wale example mein humein sirf jod aur guna pata tha. Ye nahi pata tha ki a bada hai ya b. Isliye a − b ka sign tay nahi ho sakta, aur answer ±1 hai.

### Example 2: a − b = 3 aur ab = 10. a² + b² aur a + b nikaalo.

**a² + b²:**
a² + b² = (a − b)² + 2ab = 9 + 20 = **29**

**a + b:**
(a + b)² = (a − b)² + 4ab = 9 + 40 = 49
a + b = **±7**

Jaanch: a = 5, b = 2 se a − b = 3, ab = 10, a + b = 7. Aur a = −2, b = −5 se bhi a − b = −2 − (−5) = 3, ab = 10, par a + b = −7. Dono jodiyan sahi hain, isliye ±7 ✅. Aur 5² + 2² = 29 ✅

### Example 3: a² + b² = 34 aur ab = 15. a + b nikaalo.

(a + b)² = a² + b² + 2ab = 34 + 30 = 64
a + b = **±8**

Jaanch: 3 aur 5 se 9 + 25 = 34, 3 × 5 = 15, 3 + 5 = 8 ✅. Aur −3, −5 se jod −8 aata hai ✅

Isi data se a − b bhi nikaal sakte hain: (a − b)² = 34 − 30 = 4, to a − b = ±2.

### Example 4: Nani ki paheli dobara

a + b = 10, ab = 21. (a − b) nikaalo.

(a − b)² = (a + b)² − 4ab = 100 − 84 = 16
a − b = **±4**

Jaanch: 7 − 3 = 4 ✅

### Example 5: Coefficient wala sawaal

2a + 3b = 13 aur ab = 6. 4a² + 9b² nikaalo.

Yahan 2a ko ek "A" aur 3b ko ek "B" samjho. Phir:

(2a + 3b)² = (2a)² + 2(2a)(3b) + (3b)²
169 = 4a² + 12ab + 9b²
169 = 4a² + 9b² + 12 × 6
4a² + 9b² = 169 − 72 = **97**

Jaanch: a = 2, b = 3 se 2(2) + 3(3) = 13 aur ab = 6 ✅. 4(4) + 9(9) = 16 + 81 = 97 ✅

Dhyan do, beech wala term 2 × (2a) × (3b) = **12ab** hai, sirf 2ab nahi.

## Part C: x + 1/x aur x − 1/x wala parivaar

Ab ek khaas tarah ki jodi dekhte hain: ek number x aur uska reciprocal 1/x.

### Identity lagao

a = x aur b = 1/x rakho:

(x + 1/x)² = x² + 2 · x · (1/x) + (1/x)²

Ab mazedaar baat dekho: **x · (1/x) = 1**. Beech wala term x se mukt ho gaya aur sirf **2** bacha!

**(x + 1/x)² = x² + 1/x² + 2**

Isi tarah:

**(x − 1/x)² = x² + 1/x² − 2**

Isi wajah se ye sawaal itne saaf hal hote hain. Beech mein x ka koi tukda nahi bachta, sirf ek seedha number aata hai.

### Example 6: x + 1/x = 3. x² + 1/x² aur x⁴ + 1/x⁴ nikaalo.

**x² + 1/x²:**
(x + 1/x)² = x² + 1/x² + 2
9 = x² + 1/x² + 2
x² + 1/x² = **7**

**x⁴ + 1/x⁴:** Yahan ek chhoti trick hai. x² ko naya "x" maan lo. Phir x⁴ = (x²)² aur 1/x⁴ = (1/x²)².

(x² + 1/x²)² = x⁴ + 1/x⁴ + 2
49 = x⁴ + 1/x⁴ + 2
x⁴ + 1/x⁴ = **47**

Isi tarah aage bhi chal sakte ho: har baar square karo aur 2 ghatao.

### Example 7: x − 1/x = 4. x² + 1/x² nikaalo.

(x − 1/x)² = x² + 1/x² − 2
16 = x² + 1/x² − 2
x² + 1/x² = **18**

### Example 8: x² + 1/x² = 27. x − 1/x aur x + 1/x nikaalo.

**x − 1/x:**
(x − 1/x)² = x² + 1/x² − 2 = 27 − 2 = 25
x − 1/x = **±5**

**x + 1/x:**
(x + 1/x)² = x² + 1/x² + 2 = 27 + 2 = 29
x + 1/x = **±√29**

29 perfect square nahi hai, isliye answer √29 hi rehne do. Ise decimal mein badalne ki zaroorat nahi.

### Example 9: x + 1/x = 3. x − 1/x nikaalo.

Pehle Example 6 se x² + 1/x² = 7.
(x − 1/x)² = 7 − 2 = 5
x − 1/x = **±√5**

Seedha raasta bhi hai: (x − 1/x)² = (x + 1/x)² − 4 = 9 − 4 = 5. Ye Result 4 jaisa hi hai, kyunki yahan ab = x · (1/x) = 1, to 4ab = 4.

### Example 10: x + 1/x = 5. x² + 1/x² aur x⁴ + 1/x⁴ nikaalo.

x² + 1/x² = 25 − 2 = **23**
x⁴ + 1/x⁴ = 23² − 2 = 529 − 2 = **527**

## Part D: Identities se simplify karna

### Example 11: (2x + 3)² − (2x − 3)² ko simplify karo.

Lamba raasta: dono ko kholo aur ghatao. Chhota raasta: Result 2 lagao, jahan a = 2x aur b = 3.

(a + b)² − (a − b)² = 4ab = 4 × 2x × 3 = **24x**

Jaanch: x = 1 rakho. (5)² − (−1)² = 25 − 1 = 24, aur 24 × 1 = 24 ✅

### Example 12: (a + b)² + (a − b)² ko simplify karo.

Result 3 se seedha: **2(a² + b²)**, yaani 2a² + 2b².

### Example 13: Bina square kiye nikaalo: 7.8² + 2.2² + 2(7.8)(2.2)

Ye a² + b² + 2ab ki shakal hai, jahan a = 7.8 aur b = 2.2.

= (7.8 + 2.2)² = 10² = **100**

Dekho, decimals ka lamba guna karne ki zaroorat hi nahi padi.

### Example 14: Bina square kiye nikaalo: 5.6² − 2(5.6)(1.6) + 1.6²

Ye a² − 2ab + b² hai, jahan a = 5.6 aur b = 1.6.

= (5.6 − 1.6)² = 4² = **16**

### Example 15: 51² − 49² ko 4ab se nikaalo.

51 = 50 + 1 aur 49 = 50 − 1. To a = 50, b = 1.

(a + b)² − (a − b)² = 4ab = 4 × 50 × 1 = **200**

Jaanch: 2601 − 2401 = 200 ✅

## Aam galtiyan (bachke rehna)

**Galti 1: Square root lete waqt ± bhool jana**
(a − b)² = 1 se a − b = 1 likh dena adhoora hai. Sahi answer **±1** hai, jab tak sawaal mein na likha ho ki a > b ya number positive hain.

**Galti 2: (x + 1/x)² = x² + 1/x² likhna**
Beech wala term bhool gaye! Sahi hai x² + 1/x² **+ 2**. Jaanch: x = 1 rakho. (1 + 1)² = 4, par 1 + 1 = 2. Dono alag hain.

**Galti 3: 2ab ki jagah 4ab, ya ulta**
a² + b² ke liye **2ab** ghatate hain: (a + b)² − 2ab.
(a − b)² ke liye **4ab** ghatate hain: (a + b)² − 4ab.
Confusion ho to Topic 1 wali identity likh kar dekh lo.

**Galti 4: Coefficient wale terms mein beech wala term galat**
(2a + 3b)² mein beech wala term 2 × 2a × 3b = **12ab** hai, 2ab ya 6ab nahi.

**Galti 5: x − 1/x ke square mein sign**
(x − 1/x)² = x² + 1/x² **− 2**. Yahan +2 nahi aata. Aur x² + 1/x² wala term hamesha plus hi rehta hai, kyunki square kabhi negative nahi hota.

**Galti 6: Bina jaanche answer likhna**
Jab bhi ho sake, chhote numbers (jaise 3 aur 4) rakh kar answer jaancho. 10 second ka kaam hai aur galti turant pakad mein aa jati hai.

## Quick Recap

- Topic 1 ki do identities se hi saare naye results nikalte hain. Kuch ratne ki zaroorat nahi.
- **a² + b² = (a + b)² − 2ab = (a − b)² + 2ab**
- **(a + b)² − (a − b)² = 4ab**
- **(a + b)² + (a − b)² = 2(a² + b²)**
- **(a − b)² = (a + b)² − 4ab**
- Square root lete waqt **±** lagao, kyunki 3² aur (−3)² dono 9 hain.
- **(x + 1/x)² = x² + 1/x² + 2** aur **(x − 1/x)² = x² + 1/x² − 2**, kyunki x · (1/x) = 1.
- x⁴ + 1/x⁴ ke liye x² + 1/x² ko square karke 2 ghatao.
- a² ± 2ab + b² jaisi shakal dikhe to seedha (a ± b)² likh do. Decimals ka kaam aasan ho jata hai.

## Practice Questions

1. If a + b = 9 and ab = 20, find:
   (a) a² + b²
   (b) (a − b)²

2. If a − b = 4 and ab = 21, find:
   (a) a² + b²
   (b) a + b

3. If a² + b² = 41 and ab = 20, find a + b and a − b.

4. If x + 1/x = 4, find x² + 1/x² and x⁴ + 1/x⁴.

5. If x − 1/x = 3, find x² + 1/x².

6. If x² + 1/x² = 51, find x − 1/x and x + 1/x.

7. Simplify: (3x + 4)² − (3x − 4)²

8. Evaluate without finding each square separately: 8.5² − 2(8.5)(1.5) + 1.5²

9. If 3x + 2y = 12 and xy = 6, find 9x² + 4y².

10. State whether true or false, with a reason: "If a² = 9, then a = 3."

### Answers

1. (a) a² + b² = (a + b)² − 2ab = 81 − 40 = **41**
   (b) (a − b)² = (a + b)² − 4ab = 81 − 80 = **1**
   Jaanch: numbers 4 aur 5 hain. 16 + 25 = 41 ✅, (5 − 4)² = 1 ✅

2. (a) a² + b² = (a − b)² + 2ab = 16 + 42 = **58**
   (b) (a + b)² = (a − b)² + 4ab = 16 + 84 = 100, to a + b = **±10**
   Jaanch: a = 7, b = 3 se jod 10 aata hai, aur a = −3, b = −7 se jod −10 ✅

3. (a + b)² = 41 + 40 = 81, to a + b = **±9**
   (a − b)² = 41 − 40 = 1, to a − b = **±1**
   Jaanch: 4 aur 5 se 16 + 25 = 41, 4 × 5 = 20 ✅

4. x² + 1/x² = 16 − 2 = **14**
   x⁴ + 1/x⁴ = 14² − 2 = 196 − 2 = **194**

5. (x − 1/x)² = x² + 1/x² − 2, to 9 = x² + 1/x² − 2, aur x² + 1/x² = **11**

6. (x − 1/x)² = 51 − 2 = 49, to x − 1/x = **±7**
   (x + 1/x)² = 51 + 2 = 53, to x + 1/x = **±√53**

7. Result 2 se, a = 3x aur b = 4: 4ab = 4 × 3x × 4 = **48x**
   Jaanch: x = 1 par (7)² − (−1)² = 49 − 1 = 48 ✅

8. Ye (a − b)² ki shakal hai, a = 8.5 aur b = 1.5: (8.5 − 1.5)² = 7² = **49**

9. (3x + 2y)² = 9x² + 12xy + 4y²
   144 = 9x² + 4y² + 12 × 6
   9x² + 4y² = 144 − 72 = **72**
   Jaanch: x = 2, y = 3 se 6 + 6 = 12 aur xy = 6 ✅. 9(4) + 4(9) = 36 + 36 = 72 ✅

10. **False** ❌. (−3)² bhi 9 hai, isliye a = 3 ya a = −3, yaani a = ±3.
