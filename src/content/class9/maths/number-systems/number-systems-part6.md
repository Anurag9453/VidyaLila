# Topic 6: Laws of Exponents aur Rational Exponents

Pichle do topics mein humne roots ke saath khoob kaam kiya. Topic 4 mein **nth root** dekha: ⁿ√a wo number hai jiski n-vi power a ho. Aur Topic 5 mein denominator se roots hatana (rationalisation) seekha, jaise 1/√2 = √2/2, ya conjugate se 1/(2 + √3) = 2 − √3.

Ab ek mazedaar sawaal. Exponents to hum Class 8 se jaante hain: 2³ = 8, 2⁻¹ = 1/2. Par **kya exponent ek fraction ho sakta hai?** Jaise 2^(1/2)? Iska matlab kya hoga?

Is topic mein hum dekhenge ki **roots aur exponents asal mein ek hi cheez ke do roop hain**:

> **ⁿ√a = a^(1/n)**

Yahi ek line poore topic ki chaabi hai.

---

## Ishaan ki money plant ki kahani

Ishaan ke ghar ek **money plant** hai jo bahut tezi se badhta hai. Uski pattiyon ki ginti **har din double** ho jati hai.

Aaj usme **1** patti hai (maan lo hum ginti yahin se shuru karte hain).

| Kitne din baad | Pattiyan | Exponent ki bhasha |
|---|---|---|
| 0 din | 1 | 2⁰ |
| 1 din | 2 | 2¹ |
| 2 din | 4 | 2² |
| 3 din | 8 | 2³ |

Yaani **t din baad pattiyan = 2ᵗ**. Ye to Class 8 wali baat hai.

Ab Ishaan ki chhoti behen ne poocha: **"Aadhe din baad kitni pattiyan hongi?"**

Soch ke dekho. Aadhe din mein pattiyan kisi number **m** se guna ho jati hain. Phir agle aadhe din mein bhi **m** se guna hongi. Do aadhe din = ek poora din, aur ek poore din mein pattiyan **2 guna** hoti hain. To:

**m × m = 2**, yaani **m² = 2**, yaani **m = √2 ≈ 1.414**

Matlab aadhe din baad pattiyan **√2 ≈ 1.41** guna hongi. Aur exponent ki bhasha mein "aadha din" = t = 1/2, to:

**2^(1/2) = √2**

Isi tarah **ek-tihai (1/3) din** ka guna m ho, to teen hisse milkar ek din banate hain: m³ = 2, yaani m = ∛2. To **2^(1/3) = ∛2**.

Aur **do-tihai (2/3) din**? Wo do baar "1/3 din" hai: (∛2)² = 2^(2/3).

Bas, aapne fractional (rational) exponent ka poora matlab samajh liya. Ab ise aaram se, ek ek kadam mein pakka karte hain.

## Part A: Class 8 ke laws, ek chhota sa recall

Exponents ke laws aap [Class 8 ke Exponents chapter](../../../class8/maths/exponents/exponents.md) mein detail mein padh chuke ho. Yahan bas ek nazar:

| Law | Kya kehta hai | Chhota example |
|---|---|---|
| Product law | aᵖ · a^q = a^(p+q) | 2³ · 2² = 2⁵ = 32 |
| Power of a power | (aᵖ)^q = a^(pq) | (3²)³ = 3⁶ = 729 |
| Quotient law | aᵖ / a^q = a^(p−q) | 5⁷ / 5⁵ = 5² = 25 |
| Product ki power | aᵖ · bᵖ = (ab)ᵖ | 2³ · 5³ = 10³ = 1000 |
| Zero exponent | a⁰ = 1 | 7⁰ = 1 |
| Negative exponent | a^(−p) = 1/aᵖ | 2⁻³ = 1/8 |

**Is topic ki khushkhabri:** jab base **a, b positive real numbers** hon, to ye saare laws **rational exponents (p, q fractions) ke liye bhi bilkul waise hi chalte hain.** Koi naya law ratna nahi hai. Bas ab p aur q fraction bhi ho sakte hain.

## Part B: a^(1/n) = ⁿ√a (roots exponent ke kapde mein)

Kahani mein dekha ki 2^(1/2) = √2. Ab ise general banate hain.

Maan lo x = a^(1/n). Ab dono taraf n-vi power lo, aur Part A ka "power of a power" law lagao:

xⁿ = (a^(1/n))ⁿ = a^((1/n) × n) = a¹ = a

To x wo number hai jiski n-vi power a hai. Topic 4 mein dekha tha ki yahi to **ⁿ√a** hai!

> **a^(1/n) = ⁿ√a**

| Exponent form | Root form | Value |
|---|---|---|
| 64^(1/2) | √64 | **8** (kyunki 8² = 64) |
| 125^(1/3) | ∛125 | **5** (kyunki 5³ = 125) |
| 32^(1/5) | ⁵√32 | **2** (kyunki 2⁵ = 32) |
| 81^(1/4) | ⁴√81 | **3** (kyunki 3⁴ = 81) |
| 1000^(1/3) | ∛1000 | **10** (kyunki 10³ = 1000) |

**Yaad rakhne ka tareeka:** fraction ka **neeche wala number (denominator) root batata hai**. 1/2 matlab square root, 1/3 matlab cube root, 1/5 matlab 5th root.

## Part C: a^(m/n), jab upar bhi koi number ho

Ab 9^(3/2) jaisa kuch aaye to? Exponent 3/2 ko aise todo:

3/2 = (1/2) × 3

Part A ke "power of a power" law se:

9^(3/2) = (9^(1/2))³ = (√9)³ = 3³ = **27**

> **a^(m/n) = (ⁿ√a)^m = ⁿ√(a^m)**
>
> **Neeche wala (n) = kaunsa root. Upar wala (m) = kaunsi power.**

Dono tareeke same answer dete hain. Check karo 32^(2/5):

- **Pehle root, phir power:** ⁵√32 = 2, phir 2² = **4**
- **Pehle power, phir root:** 32² = 1024, phir ⁵√1024 = **4** (kyunki 4⁵ = 1024)

Same! ✅ Par dhyan do, **pehle root lene se numbers chhote rehte hain**, isliye wahi tareeka aasan hai.

### Solved examples

**Example 1:** 16^(3/4)
⁴√16 = 2, phir 2³ = **8**
Jaanch: 8⁴ = 4096 aur 16³ = 4096 ✅ (yaani 8 sach mein 16³ ka 4th root hai)

**Example 2:** 125^(−1/3)
Negative exponent matlab ulta (Class 8 wala law): 125^(−1/3) = 1/125^(1/3) = 1/∛125 = **1/5**
Jaanch: (1/5)³ = 1/125, yaani 1/5 sach mein 1/125 ka cube root hai, aur 125^(−1/3) = (1/125)^(1/3) ✅

**Example 3:** (1/27)^(−2/3)
Pehle negative hatao, fraction ulta karo: (1/27)^(−2/3) = 27^(2/3)
∛27 = 3, phir 3² = **9**
Jaanch: 9³ = 729 aur 27² = 729 ✅

**Example 4:** (64/125)^(−2/3)
Ulta karo: (125/64)^(2/3)
∛125 = 5, ∛64 = 4, to ∛(125/64) = 5/4
Phir (5/4)² = **25/16**

**Example 5:** 16^(3/4) × 81^(−1/4)
16^(3/4) = 8 (Example 1 se)
81^(−1/4) = 1/⁴√81 = 1/3
Answer = 8 × 1/3 = **8/3**

### Base positive kyun hona chahiye?

Is topic mein hum hamesha **positive base** lete hain. Kyun? Ek chhoti si gadbad dekho:

- (−4)^(1/2) = √(−4). Aisa koi real number nahi jiska square −4 ho (square hamesha 0 ya positive hota hai). To ye real numbers mein **hai hi nahi**.
- Aur (−8)^(1/3) = −2 lagta hai (kyunki (−2)³ = −8). Par 1/3 = 2/6 bhi hai. Agar (−8)^(2/6) ko "pehle power, phir root" se karein: (−8)² = 64, phir ⁶√64 = **2**. Ek hi cheez ke do alag answer (−2 aur 2)!

Isliye negative base wale rational exponents se abhi door rehte hain. Ye baatein **aage ki classes** mein aati hain. Is topic ke saare laws **positive base** ke liye pakke hain.

## Part D: Laws ke saath simplify karna

Ab Part A ke laws rational exponents par lagaate hain.

**Example 1:** 2^(2/3) · 2^(1/3)
Same base, guna, to exponents jodo: 2^(2/3 + 1/3) = 2¹ = **2**

**Example 2:** (3^(1/3))⁷
Power ki power, to exponents guna: 3^((1/3) × 7) = **3^(7/3)**

**Example 3:** 11^(1/2) / 11^(1/4)
Same base, bhaag, to exponents ghatao: 11^(1/2 − 1/4) = **11^(1/4)**
(1/2 − 1/4 = 2/4 − 1/4 = 1/4)

**Example 4:** 7^(1/2) · 8^(1/2)
Same exponent, alag base, to base guna karo: (7 × 8)^(1/2) = **56^(1/2)** (yaani √56)

**Example 5:** 5^(1/2) · 20^(1/2)
(5 × 20)^(1/2) = 100^(1/2) = **10**
Jaanch: √5 × √20 = √100 = 10. Topic 4 ka √a × √b = √(ab) bhi yahi kehta hai ✅

**Example 6:** √a · ∛a (a positive)
Pehle root ko exponent mein badlo: √a = a^(1/2), ∛a = a^(1/3)
a^(1/2) · a^(1/3) = a^(1/2 + 1/3) = a^(3/6 + 2/6) = **a^(5/6)**
Wapas root form mein: ⁶√(a⁵)

**Example 7:** (x^(1/2) · x^(1/3))⁶
Andar: x^(5/6) (Example 6 jaisa). Phir power ki power: x^((5/6) × 6) = **x⁵**

**Tip:** Roots ke saath guna-bhaag mushkil lage, to **sab ko exponent form mein badlo**, laws lagao, phir chahiye to wapas root form mein le aao. Exponent form mein fractions jodna roots ke saath jhoojhne se kahin aasan hai.

## Part E: "x nikalo" wale sawaal

Agar do powers barabar hain aur **base same** hai, to **exponents bhi barabar** honge. Trick ye hai ki dono taraf **same base** bana lo.

**Example 1:** 9^x = 27
9 = 3², 27 = 3³
(3²)^x = 3³, yaani 3^(2x) = 3³
2x = 3, **x = 3/2**
Jaanch: 9^(3/2) = (√9)³ = 3³ = 27 ✅

**Example 2:** 8^x = 4
2^(3x) = 2²
3x = 2, **x = 2/3**
Jaanch: 8^(2/3) = (∛8)² = 2² = 4 ✅

**Example 3:** 2^x = 32^(1/5)
32^(1/5) = ⁵√32 = 2 = 2¹
**x = 1**

**Example 4:** 25^x = 1/5
5^(2x) = 5^(−1)
2x = −1, **x = −1/2**
Jaanch: 25^(−1/2) = 1/√25 = 1/5 ✅

**Example 5:** 27^x = 9^(x+1)
3^(3x) = 3^(2(x+1)) = 3^(2x+2)
3x = 2x + 2, **x = 2**
Jaanch: 27² = 729 aur 9³ = 729 ✅

**Example 6:** (√3)^x = 9
√3 = 3^(1/2), to 3^(x/2) = 3²
x/2 = 2, **x = 4**
Jaanch: (√3)⁴ = ((√3)²)² = 3² = 9 ✅

## Aam galtiyan (bachke rehna)

**Galti 1: Exponent ko seedha guna kar dena**
8^(2/3) ≠ 8 × 2/3 = 16/3.
Sahi: ∛8 = 2, phir 2² = **4**. Exponent "kya karna hai" batata hai, guna karne wala number nahi hai.

**Galti 2: a^(1/2) ko a/2 samajhna**
16^(1/2) = 4, par 16/2 = 8. Dono alag!
(Dhokha isliye hota hai kyunki 4^(1/2) = 2 aur 4/2 = 2 sanyog se barabar aa jaate hain. Har number ke saath aisa nahi hota.)

**Galti 3: Jod par root baant dena**
(a + b)^(1/2) ≠ a^(1/2) + b^(1/2)
Check: (9 + 16)^(1/2) = √25 = 5, par √9 + √16 = 3 + 4 = 7.
Root (aur power) **guna par** baantta hai, **jod par nahi**. Ye wahi galti hai jo Class 8 mein (a + b)² ke saath dekhi thi.

**Galti 4: Negative exponent ko negative answer samajhna**
125^(−1/3) = 1/5, **−5 nahi**.
Negative exponent matlab "ulta karo", minus nahi.

**Galti 5: Guna mein exponents ko guna kar dena**
2^(1/2) · 2^(1/3) ≠ 2^(1/6).
Same base ka guna hai, to exponents **jodte** hain: 2^(1/2 + 1/3) = **2^(5/6)**. Exponents tab guna hote hain jab **power ki power** ho, jaise (2^(1/2))^(1/3) = 2^(1/6).

**Galti 6: m aur n ki jagah ulat dena**
8^(2/3) mein **3 root hai** (neeche wala) aur **2 power hai** (upar wala). Agar ulta karke √8 ka cube le liya, to 8^(3/2) ban jayega, jo alag number hai (≈ 22.6).

**Galti 7: Negative base par bina soche laws lagana**
(−4)^(1/2) real number nahi hai. Is topic ke laws **sirf positive base** ke liye hain.

## Quick Recap

- Class 8 ke saare exponent laws **positive real base** aur **rational exponents** ke liye bhi chalte hain:
  aᵖ · a^q = a^(p+q), (aᵖ)^q = a^(pq), aᵖ / a^q = a^(p−q), aᵖbᵖ = (ab)ᵖ, a⁰ = 1, a^(−p) = 1/aᵖ.
- **a^(1/n) = ⁿ√a**: fraction ka denominator root batata hai.
- **a^(m/n) = (ⁿ√a)^m = ⁿ√(a^m)**: neeche wala root, upar wala power. Pehle root lena aasan hai.
- Negative exponent = **ulta karo**: a^(−m/n) = 1/a^(m/n).
- Roots ke sawaal mein **sab kuch exponent form mein badlo**, laws lagao, phir wapas aao.
- **x nikalne** ke liye dono taraf same base banao, phir exponents barabar karo.
- Root guna par baantta hai, **jod par nahi**: (a + b)^(1/2) ≠ a^(1/2) + b^(1/2).
- Is topic mein base hamesha **positive** rakha. Negative base wali baatein aage ki classes mein.

## Practice Questions

1. Find the value of:
   (a) 49^(1/2)
   (b) 27^(1/3)
   (c) 243^(1/5)
   (d) 64^(2/3)
   (e) 16^(−3/4)
   (f) (1/32)^(−2/5)

2. Simplify, writing the answer as a single power:
   (a) 3^(1/2) · 3^(1/4)
   (b) (5^(1/4))⁸
   (c) 13^(1/5) / 13^(1/3)
   (d) 2^(1/3) · 5^(1/3)

3. Write in exponent form:
   (a) ⁴√7
   (b) √(x³)
   (c) 1/∛5

4. Write in root form:
   (a) 6^(2/5)
   (b) a^(3/4)

5. Find x:
   (a) 4^x = 32
   (b) 125^x = 25
   (c) 81^x = 1/3

6. Simplify: (25/9)^(−3/2)

7. Simplify: a^(1/2) · a^(1/3) · a^(1/6), where a > 0.

8. State whether each statement is true or false. Give a reason.
   (a) 9^(1/2) + 16^(1/2) = 25^(1/2)
   (b) 8^(1/3) · 8^(2/3) = 8
   (c) 100^(−1/2) = −10
   (d) (2^(1/2))⁴ = 4

### Answers

1. (a) √49 = **7**
   (b) ∛27 = **3**
   (c) ⁵√243 = **3** (kyunki 3⁵ = 243)
   (d) ∛64 = 4, phir 4² = **16**
   (e) 16^(3/4) = (⁴√16)³ = 2³ = 8, to 16^(−3/4) = **1/8**
   (f) Ulta karo: 32^(2/5) = (⁵√32)² = 2² = **4**
2. (a) 3^(1/2 + 1/4) = **3^(3/4)**
   (b) 5^((1/4) × 8) = 5² = **25**
   (c) 13^(1/5 − 1/3) = 13^(3/15 − 5/15) = **13^(−2/15)**
   (d) Same exponent, base guna: **10^(1/3)**
3. (a) **7^(1/4)**
   (b) **x^(3/2)**
   (c) **5^(−1/3)**
4. (a) **⁵√(6²)**, yaani ⁵√36
   (b) **⁴√(a³)**
5. (a) 2^(2x) = 2⁵, to 2x = 5, **x = 5/2**
   Jaanch: 4^(5/2) = (√4)⁵ = 2⁵ = 32 ✅
   (b) 5^(3x) = 5², to 3x = 2, **x = 2/3**
   Jaanch: 125^(2/3) = (∛125)² = 5² = 25 ✅
   (c) 3^(4x) = 3^(−1), to 4x = −1, **x = −1/4**
   Jaanch: 81^(−1/4) = 1/⁴√81 = 1/3 ✅
6. Ulta karo: (9/25)^(3/2). √(9/25) = 3/5, phir (3/5)³ = **27/125**
7. a^(1/2 + 1/3 + 1/6) = a^(3/6 + 2/6 + 1/6) = a¹ = **a**
8. (a) **False** ❌. 3 + 4 = 7, par √25 = 5. Root jod par nahi baantta.
   (b) **True** ✅. 8^(1/3 + 2/3) = 8¹ = 8.
   (c) **False** ❌. 100^(−1/2) = 1/√100 = **1/10**. Negative exponent ulta karta hai, minus nahi banata.
   (d) **True** ✅. 2^((1/2) × 4) = 2² = 4.
