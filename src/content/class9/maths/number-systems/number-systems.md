# Topic 1: Numbers ka Parivaar: Natural, Whole, Integers, Rational Numbers aur Number Line

Ab tak aapne bahut saare numbers use kiye hain: ginti wale numbers, minus wale numbers, fractions. Par kya kabhi socha ki ye sab ek hi **parivaar** ke log hain? Har naya number tab aaya jab insaan ko ek nayi zaroorat padi. Is topic mein hum is parivaar ko shuru se milenge, dekhenge kaun kiske andar aata hai, aur sabko ek seedhi line par unki sahi jagah bithayenge.

---

## Numbers ke bade hone ki kahani

Bahut pehle ek gaon mein **Dhanno** naam ki ek charwaahi rehti thi. Uske paas bhedein (sheep) thin.

**Pehli zaroorat: ginna.**
Subah wo bhedon ko charaane le jaati, aur shaam ko dekhna hota ki sab laut aayin ya nahi. To wo ginti thi: 1, 2, 3, 4, ... Ye sabse purane numbers hain. Inhe **natural numbers** kehte hain, kyunki ginna insaan ke liye sabse "natural" kaam tha.

**Doosri zaroorat: "kuch nahi".**
Ek din toofan aaya aur saari bhedein bhaag gayin. Baada (pen) khaali tha. Ab "kitni bhedein hain?" ka jawab kya hoga? **Kuch nahi.** Iske liye ek naya number chahiye tha: **0**. Ginti wale numbers mein 0 jod do, to milte hain **whole numbers**: 0, 1, 2, 3, ...

**Teesri zaroorat: udhaar aur thand.**
Dhanno ne padosi se 5 bhedein udhaar li. Ab uske paas apni koi bhed nahi thi, balki 5 **dene** baaki the. Ise likhne ke liye "minus" wale numbers aaye: **−5**. Pahadon mein sardi ki raat ka temperature bhi 0 se neeche chala jata hai, jaise −3°C. Positive numbers, 0 aur negative numbers mil kar bane **integers**: ..., −3, −2, −1, 0, 1, 2, 3, ...

**Chauthi zaroorat: baantna.**
Mele se Dhanno gud ki ek **bheli** (jaggery ka block) laayi aur use apne 4 bachchon mein barabar baantna tha. Har bachche ko poori bheli nahi mili, balki **1/4** mila. Ab aise numbers chahiye the jo "hisse" bata sakein. Ye bane **rational numbers** (fractions jaise numbers).

Dekho, har baar purane numbers chhote pad gaye, aur parivaar mein ek naya sadasya jud gaya. Par purane numbers kahin gaye nahi. Wo naye parivaar ka hissa ban gaye. Yahi is topic ki sabse badi baat hai.

| **Whole numbers (W)** | Natural numbers + 0 | 0, 1, 2, 3, ... |
| **Integers (Z)** | Whole numbers + unke negative | ..., −2, −1, 0, 1, 2, ... |

Letters kahan se aaye? **N** = Natural, **W** = Whole, **Z** = German shabd "Zahlen" (matlab "numbers"), aur **Q** = "Quotient" (bhaag ka nateeja), kyunki rational number ek division hi to hai.

## Part A: Parivaar ke sadasya

### Natural numbers (N)

**N = {1, 2, 3, 4, 5, ...}**

- Ye 1 se shuru hote hain.
- Inka koi ant nahi. Kitna bhi bada number socho, usme 1 jod kar aur bada mil jayega.
- **0 natural number nahi hai.** Ginti hamesha 1 se shuru hoti hai.

### Whole numbers (W)

**W = {0, 1, 2, 3, 4, ...}**

- Natural numbers mein bas ek naya sadasya juda: **0**.
- To har natural number ek whole number bhi hai. Par 0 whole number hai, natural nahi.

### Integers (Z)

**Z = {..., −3, −2, −1, 0, 1, 2, 3, ...}**

- Isme teen tarah ke log hain: positive integers (1, 2, 3, ...), **zero**, aur negative integers (−1, −2, −3, ...).
- 0 na positive hai, na negative. Wo beech mein khada hai.

Roz ki zindagi mein integers:
- Bank account mein ₹500 jama = +500, ₹200 udhaar = −200
- Lift mein ground floor = 0, basement = −1, pehli manzil = +1
- Samudra tal (sea level) se upar pahaad = +, neeche ki gehrai = −

### Rational numbers (Q)

Koi bhi number jise **p/q** ki shakal mein likh sakein, jahan:
- p aur q dono **integers** hon, aur
- **q ≠ 0** ho,

wo **rational number** hai.

Examples:
- 3/4 (p = 3, q = 4)
- −2/5 (p = −2, q = 5)
- **7**, kyunki 7 = 7/1
- **0**, kyunki 0 = 0/1
- **−6**, kyunki −6 = −6/1

Dhyan do: **har integer bhi rational number hai**, kyunki use 1 ke upar likh sakte ho.

### q ≠ 0 kyun?

Division ka matlab hai "kis number se guna karein ki ye mil jaye".

- 6/2 = 3, kyunki 2 × **3** = 6. Ek pakka jawab.
- 6/0 = ? Matlab 0 × **?** = 6. Par 0 ko kisi bhi number se guna karo, jawab 0 hi aata hai, kabhi 6 nahi. **Koi jawab hi nahi hai.**

Gud wali kahani mein socho: 1 bheli ko **0 bachchon** mein baantna. Kisko kitna milega? Ye sawaal hi bematlab hai. Isliye denominator kabhi 0 nahi ho sakta.

## Part B: Equivalent fractions aur lowest form

### Ek hi number, kai kapde

Gud ki bheli ko:
- 2 barabar hisson mein kaato, 1 hissa lo: **1/2**
- 4 barabar hisson mein kaato, 2 hisse lo: **2/4**
- 10 barabar hisson mein kaato, 5 hisse lo: **5/10**

Teeno baar aapke haath mein **utna hi gud** aaya. To 1/2, 2/4, 5/10 alag dikhte hain, par **ek hi rational number** hain. Jaise ek hi insaan alag alag kapde pehne, insaan wahi rehta hai.

**Rule:** Numerator aur denominator dono ko **ek hi non-zero number** se guna ya bhaag do, to fraction ki value nahi badalti.

3/5 = (3 × 4)/(5 × 4) = 12/20

### Lowest form

Jab numerator aur denominator ka **koi common factor (1 ke alawa) na bache**, to fraction **lowest form** mein hai.

Tarika: dono ko unke **HCF** se bhaag do.

**Example 1:** 18/24
HCF(18, 24) = 6
18/24 = (18 ÷ 6)/(24 ÷ 6) = **3/4**

**Example 2:** −15/35
HCF(15, 35) = 5
−15/35 = **−3/7**

**Example 3:** 45/−60
Pehle minus ko upar le aao: 45/−60 = −45/60. (Hum aam taur par denominator ko positive rakhte hain.)
HCF(45, 60) = 15
= **−3/4**

Jaanch: −3/4 = (−3 × 15)/(4 × 15) = −45/60 ✅

## Part C: Kaun kis parivaar mein? (N ⊂ W ⊂ Z ⊂ Q)

Kahani mein dekha ki har naya parivaar purane ko apne andar le leta hai. Ise ek dibbe ke andar dibba jaisa socho:

```
 +----------------------------------------------------+
 |  Q: Rational numbers        3/4   -2/5   1/2       |
 |   +-------------------------------------------+    |
 |   |  Z: Integers        -1   -2   -3   -10    |    |
 |   |   +-----------------------------------+   |    |
 |   |   |  W: Whole numbers        0        |   |    |
 |   |   |   +---------------------------+   |   |    |
 |   |   |   |  N: Natural   1, 2, 3, ...|   |   |    |
 |   |   |   +---------------------------+   |   |    |
 |   |   +-----------------------------------+   |    |
 |   +-------------------------------------------+    |
 +----------------------------------------------------+
```

Isko maths mein aise likhte hain: **N ⊂ W ⊂ Z ⊂ Q**. (Sign "⊂" ka matlab hai "ke andar aata hai".)

Matlab:
- Har natural number ek whole number bhi hai.
- Har whole number ek integer bhi hai.
- Har integer ek rational number bhi hai.

Par ulta hamesha sach nahi:
- 0 whole hai, natural nahi.
- −4 integer hai, whole nahi.
- 2/3 rational hai, integer nahi.

### Kaun kahan? (table)

| Number | Natural? | Whole? | Integer? | Rational? |
|---|---|---|---|---|
| 7 | Haan | Haan | Haan | Haan (7/1) |
| 0 | Nahi | Haan | Haan | Haan (0/1) |
| −5 | Nahi | Nahi | Haan | Haan (−5/1) |
| 3/4 | Nahi | Nahi | Nahi | Haan |
| −2/3 | Nahi | Nahi | Nahi | Haan |
| 9/3 | **Haan** | **Haan** | **Haan** | Haan |
| −12/4 | Nahi | Nahi | **Haan** | Haan |

Last do rows dhyan se dekho. **9/3 dikhne mein fraction hai, par 9/3 = 3 hai**, jo natural number hai. Aur −12/4 = −3, jo integer hai. Kisi number ko pehchanne se pehle **use simplify karo**.

## Part D: Number line par numbers

### Number line kaise banti hai

1. Ek seedhi line kheencho.
2. Beech mein ek point lo, use **0** kaho.
3. 0 ke right mein barabar doori par 1, 2, 3, ... lagao.
4. 0 ke left mein usi doori par −1, −2, −3, ... lagao.

```
 <--+-----+-----+-----+-----+-----+-----+-----+-->
   -3    -2    -1     0     1     2     3     4
```

- Right ki taraf jao to number **bada** hota hai.
- Left ki taraf jao to number **chhota** hota hai.
- Isliye −3 < −1, kyunki −3 zyada left mein hai. (Thand mein −3°C, −1°C se zyada thanda hota hai.)

Natural numbers sirf 1 ke right wale hisse par hain. Whole numbers 0 se shuru. Integers dono taraf.

### Rational numbers ko number line par lagana

**Tarika:** Pehle dekho number kin do integers ke beech hai. Phir us hisse ko **denominator jitne barabar tukdon** mein baanto, aur numerator jitne tukde gino.

**Example 1: 3/4**

3/4, 0 aur 1 ke beech hai (kyunki 3 < 4). 0 se 1 tak ke hisse ko **4 barabar** tukdon mein baanto, aur 0 se **3 tukde** right jao.

```
     0    1/4   2/4   3/4    1
 ----+-----+-----+-----*-----+----
                       ^
                      3/4
```

**Example 2: −3/4**

Ye 0 aur −1 ke beech hai, **0 ke left** mein. 0 se −1 tak ke hisse ko 4 tukdon mein baanto, aur 0 se **3 tukde left** jao.

```
    -1   -3/4  -2/4  -1/4    0
 ----+-----*-----+-----+-----+----
           ^
         -3/4
```

**Example 3: 7/3**

Pehle mixed fraction banao: 7 ÷ 3 = 2, baaki 1. To **7/3 = 2⅓** (2 poore aur 1/3).
Matlab ye 2 aur 3 ke beech hai. 2 se 3 ke hisse ko **3 tukdon** mein baanto, aur 2 se **1 tukda** right jao.

```
     2    2⅓    2⅔    3
 ----+-----*-----+-----+----
           ^
          7/3
```

Jaanch: 2⅓ = (2 × 3 + 1)/3 = 7/3 ✅

**Example 4: −5/2**

−5/2 = −2½. Ye −2 aur −3 ke beech hai. −2 se −3 tak ke hisse ko 2 tukdon mein baanto, aur −2 se 1 tukda **left** jao.

```
    -3   -5/2   -2
 ----+-----*-----+----
           ^
         -5/2
```

## Part E: Do rational numbers ke beech kitne numbers?

Do lagaatar integers, jaise 3 aur 4, ke beech **koi integer nahi** hota. Kya rational numbers ke saath bhi aisa hai? Chalo dekhte hain.

### Tarika 1: Beech ka number (average)

Do numbers a aur b ke beech hamesha ek number hota hai: unka average **(a + b)/2**. Ye theek beech mein hota hai.

**Example 1:** 1/2 aur 1 ke beech ek rational number dhundo.

(1/2 + 1)/2 = (3/2)/2 = **3/4**

Jaanch: 1/2 = 2/4 aur 1 = 4/4. To 2/4 < 3/4 < 4/4 ✅

**Example 2:** 1 aur 2 ke beech **teen** rational numbers dhundo.

- 1 aur 2 ka beech: (1 + 2)/2 = **3/2**
- 1 aur 3/2 ka beech: (1 + 3/2)/2 = (5/2)/2 = **5/4**
- 3/2 aur 2 ka beech: (3/2 + 2)/2 = (7/2)/2 = **7/4**

To 1 < 5/4 < 3/2 < 7/4 < 2.

Jaanch: Sabko 4 ke denominator par le aao: 4/4 < 5/4 < 6/4 < 7/4 < 8/4 ✅

### Tarika 2: Denominator bada karo

Jab kai numbers chahiye hon, to ye tarika tez hai.

**Example 3:** 3/5 aur 4/5 ke beech **5** rational numbers dhundo.

Pehli nazar mein lagta hai ki 3 aur 4 ke beech kuch nahi hai. Par dhyan do, hum **numerators** nahi, **numbers** dhund rahe hain.

Step 1: Humein 5 numbers chahiye, to numerator aur denominator dono ko **5 + 1 = 6** se guna karo.
- 3/5 = 18/30
- 4/5 = 24/30

Step 2: Ab beech ke numerators lo: 19, 20, 21, 22, 23.

**Answer:** 19/30, 20/30, 21/30, 22/30, 23/30

Inhe chaho to simplify kar sakte ho: 20/30 = 2/3, 21/30 = 7/10, 22/30 = 11/15.

Jaanch: 18/30 < 19/30 < 20/30 < 21/30 < 22/30 < 23/30 < 24/30 ✅

Agar 10 numbers chahiye hote to 11 se guna karte, 100 chahiye hote to 101 se. Har baar jagah ban jati!

### Kitne numbers hain? Anant!

Tarika 1 ko dobara socho. Kinhi bhi do rational numbers ke beech ek naya rational number mil gaya. Ab naye aur purane ke beech phir ek mil jayega. Phir uske beech phir ek... Ye kabhi khatam nahi hota.

Ise ek **zoom** wale camera ki tarah socho:
- Door se 0 aur 1 ke beech khaali jagah dikhti hai.
- Zoom karo, to 1/2 dikhta hai.
- Aur zoom karo, to 1/4 aur 3/4 bhi dikhte hain.
- Aur zoom karo, to 1/8, 3/8, 5/8, 7/8 bhi...

Jitna zoom karo, utne naye rational numbers dikhte jaate hain.

> **Kinhi bhi do alag rational numbers ke beech anant (infinitely many) rational numbers hote hain.**

Isliye kehte hain ki rational numbers number line par bahut **ghane** (dense) baithe hain. Integers mein beech mein khaali jagah hoti hai, par rational numbers mein kabhi "agla" number nahi hota.

(Ek mazedaar sawaal: itne ghane hone ke baad bhi, kya number line ke **saare** points rational numbers se bhar gaye? Iska jawab chaunkane wala hai, aur wo hum Topic 3 mein dekhenge.)

## Aam galtiyan (bachke rehna)

**Galti 1: 0 ko natural number samajhna**
Natural numbers 1 se shuru hote hain. 0 whole number hai, natural nahi.

**Galti 2: Denominator mein 0 likh dena**
5/0 koi number nahi hai. "0 se bhaag" ka koi matlab nahi hota. Rational number mein **q ≠ 0** hona zaroori hai.

**Galti 3: Integer ko rational na maanna**
"−6 to fraction nahi hai, isliye rational nahi" galat hai. −6 = −6/1, to ye rational hai. Har integer rational hai.

**Galti 4: Simplify kiye bina pehchanna**
−16/4 ko "fraction hai, integer nahi" mat bolna. −16/4 = −4, jo integer hai.

**Galti 5: Negative fraction ko galat taraf lagana**
−3/4 ko 0 ke **left** mein lagao, right mein nahi. Aur ye −1 aur 0 ke beech hai, −1 se aage nahi.

**Galti 6: "Beech mein koi number nahi" bol dena**
3/5 aur 4/5 ke numerators 3 aur 4 lagaatar hain, par beech mein bahut saare rational numbers hain (jaise 7/10). Denominator bada karke dekho.

**Galti 7: Mixed fraction ko galat jagah lagana**
7/3 ko "3 ke paas" mat lagao. 7/3 = 2⅓, to ye **2 aur 3 ke beech, 2 ke paas** hai.

## Quick Recap

- **N** = {1, 2, 3, ...}, **W** = {0, 1, 2, ...}, **Z** = {..., −2, −1, 0, 1, 2, ...}
- **Q** = jo p/q likhe ja sakein, p aur q integers aur **q ≠ 0**.
- **N ⊂ W ⊂ Z ⊂ Q**: har natural whole hai, har whole integer hai, har integer rational hai.
- **Equivalent fractions** ek hi rational number hain (1/2 = 2/4 = 5/10).
- **Lowest form** ke liye numerator aur denominator ko HCF se bhaag do.
- **Number line** par right = bada, left = chhota. Rational number lagane ke liye do integers ke beech ka hissa denominator jitne tukdon mein baanto.
- Do rational numbers a aur b ke beech **(a + b)/2** hamesha hota hai.
- Bahut saare numbers chahiye to **denominator bada karo**.
- Do rational numbers ke beech **anant** rational numbers hote hain.

## Practice Questions

1. Classify each number as natural, whole, integer and/or rational:
   (a) 15 (b) 0 (c) −8 (d) 2/7 (e) −16/4 (f) 12/3

2. State whether each statement is true or false. Give a reason.
   (a) Every natural number is a whole number.
   (b) Every integer is a rational number.
   (c) Every rational number is an integer.
   (d) 0 is a natural number.
   (e) 0 is a rational number.

3. Write each rational number in its lowest form:
   (a) 21/28 (b) −36/48 (c) 45/−60

4. Describe how you would represent 5/4 and −2/3 on the number line.

5. Find one rational number between 2/3 and 3/4.

6. Find four rational numbers between 1/3 and 1/2.

7. Find three rational numbers between −1 and 0.

8. Explain why 5/0 is not a rational number.

9. Are there infinitely many rational numbers between 0 and 1? Explain in one or two lines.

### Answers

1. (a) 15: natural, whole, integer, rational
   (b) 0: whole, integer, rational (natural **nahi**)
   (c) −8: integer, rational
   (d) 2/7: sirf rational
   (e) −16/4 = −4: integer, rational
   (f) 12/3 = 4: natural, whole, integer, rational

2. (a) **True** ✅. Whole numbers mein saare natural numbers aate hain, bas 0 extra hai.
   (b) **True** ✅. Har integer n = n/1 likha ja sakta hai.
   (c) **False** ❌. Jaise 1/2 rational hai, par integer nahi.
   (d) **False** ❌. Natural numbers 1 se shuru hote hain.
   (e) **True** ✅. 0 = 0/1.

3. (a) HCF(21, 28) = 7. 21/28 = **3/4**
   (b) HCF(36, 48) = 12. −36/48 = **−3/4**
   (c) Pehle 45/−60 = −45/60. HCF(45, 60) = 15. **−3/4**

4. **5/4 = 1¼.** Ye 1 aur 2 ke beech hai. 1 se 2 ke hisse ko 4 barabar tukdon mein baanto, aur 1 se 1 tukda right jao.
   **−2/3.** Ye −1 aur 0 ke beech hai. 0 se −1 ke hisse ko 3 barabar tukdon mein baanto, aur 0 se 2 tukde left jao.

5. Average lo: (2/3 + 3/4)/2. Pehle jodo: 2/3 + 3/4 = 8/12 + 9/12 = 17/12. Phir 2 se bhaag: **17/24**.
   Jaanch: 2/3 = 16/24 aur 3/4 = 18/24. To 16/24 < 17/24 < 18/24 ✅

6. Common denominator: 1/3 = 2/6 aur 1/2 = 3/6. 4 numbers chahiye, to 5 se guna karo: 10/30 aur 15/30.
   Beech ke numbers: **11/30, 12/30, 13/30, 14/30** (yaani 11/30, 2/5, 13/30, 7/15).

7. −1 = −4/4 aur 0 = 0/4. Beech mein: **−3/4, −2/4 (= −1/2), −1/4**.

8. 5/0 ka matlab hai "kis number ko 0 se guna karein ki 5 aaye". Koi bhi number 0 se guna karne par 0 hi deta hai, 5 kabhi nahi. Isliye 5/0 ka koi jawab nahi, aur rational number ki shart **q ≠ 0** bhi toot jati hai.

9. **Haan.** 0 aur 1 ke beech 1/2 hai. Phir 0 aur 1/2 ke beech 1/4 hai, phir 0 aur 1/4 ke beech 1/8... Har baar beech ka number nikal sakte hain, ye kabhi khatam nahi hota.
